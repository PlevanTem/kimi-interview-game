# IDEATION — 把“奥德赛”压缩成可玩的 3–5 分钟

> **状态：已撤回，不可用于 Gate 1。** 本文错误地把 Demo 的 3–5 分钟、单场景与单动词预算当成完整游戏概念的淘汰条件，因而系统性压低了长流程、多系统与多场景方向。保留本文只为审计；后续须基于 `brief-odyssey-reimagined-v2` 重新发散。

## 结论

最适合本项目的不是“缩小版航海 RPG”，而是**把信息不对称、诱惑和不可避免的代价压进一个可重复动作**。奥德修斯的独特性不在战斗力，而在 `mētis`（机智、计谋、适应）：玩家应该通过读懂局势、诱导强敌或承担代价来赢，而不是清空敌人血条。

推荐进入 DEFINE 的玩法类型依次为：

1. **诱导型 Boss 谜题**：用声音欺骗独眼巨人；主题、动作和反馈最一致。
2. **风险航线动作**：在斯库拉与卡律布狄斯之间主动选择损失；选择最有重量。
3. **空间拆线防守**：以佩涅洛佩视角抽走织线、改写宫殿路径；视觉最原创，但教学风险最高。

这些排序是概念阶段的独立估算，不是玩家测试结论。

## 反驳：为什么不先做“完整漂流”“希腊战神”或 Roguelite

- **开放海域会稀释主题。** 岛屿、船员、资源、随机事件、成长和多场景都在争夺开发预算，但没有任何一项自动产生“奥德赛感”。
- **纯战斗会选错英雄特征。** 《奥德赛》最可转成系统的段落，常是靠改写规则或接受损失脱困；把它做成普通连招战斗，只剩希腊皮肤。
- **Roguelite 的重复结构与漫长归途相容，但与本轮 3–5 分钟、单场景、单核心动词相冲突。** 它需要内容池、成长和跨局差异，当前没有预算。
- **叙事分支容易把关键选择变成菜单。** 本轮要求基础几何也能证明乐趣，因此后果必须发生在场内，而不是只出现在对白框里。

## 设计透镜

本轮采用 [Jesse Schell 的“设计透镜”方法](https://schellgames.com/art-of-game-design?trk=public_post_comment-text)中最适合此任务的五个问题，不把它们当成答案：

1. **核心体验**：去掉希腊名词与美术后，玩家是否仍在“以智胜强、为归途付代价”？
2. **核心玩具**：一个动作在无关卡、无对白、无成长时，是否仍值得重复 5 次？
3. **有意义的选择**：两个选项是否在信息、风险或代价上真实不同，而非一个正确答案加一个陷阱？
4. **可读反馈**：玩家能否从世界变化解释成功或失败，不依赖教程文字？
5. **范围**：基础几何、少量状态机和一个场景能否验证上述四点？

## 淘汰测试

任何方向触发以下任一项，就不进入本轮三个候选：

- 去掉角色名后只是常规战斗、常规航行或常规节奏游戏。
- 需要第二场景、成长树、物品栏、对话树或内容池才能产生变化。
- 玩家失败后只能得到数值提示，无法从场内对象解释因果。
- 核心 NPC 需要开放式规划、生成式对话或复杂群体 AI 才能成立。
- 第一次可玩版本需要正式角色、船、水体或布料资产才能判断有无乐趣。
- 成功只有唯一答案，重复第二次时没有更好的判断或执行空间。

## 发散结论

- **推荐保留**：诱导 Boss、风险航线、空间拆线。三者分别验证“骗过强敌”“接受代价”“以等待和重构掌控家园”，不是同一机制换皮。
- **备用机制 spike**：十二斧孔。如果前三者灰盒均无法在 30 秒内教会，弓箭方向是范围最安全的退路，但不应因易做而自动胜出。
- **暂缓**：塞壬节奏。声音与束缚的主题很强，但动作—反馈链尚不能用一句话说明；先不占 Gate 1 名额。
- **淘汰**：完整 Roguelite、开放海域和普通角色动作。它们需要更多内容，却没有提供更强的主题证明。
