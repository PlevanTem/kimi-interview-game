# DEFINE — 三个 Gate 1 游戏 Brief

> **状态：已撤回，不可选择。** 三案不一定是坏点子，但其范围、评分和排名由错误的 3–5 分钟完整体验约束塑造，当前 Gate 1 已退回 `not_started`。这些内容只保留为历史证据。

## 结论

**推荐顺序：A《无人呼救》 > B《六盏灯》 > C《夜织伊萨卡》。**

推荐 A，不是因为它最像现有游戏，而是因为它用最少系统同时兑现四件事：奥德修斯式机智、一个可重复动作、一个有身体重量的敌人、以及基础几何可验证的因果。B 的选择更尖锐、画面更强，但“可接受的损失”很容易被玩家读成设计者强迫。C 最原创，却承担最高的教学和路径可视化风险。

这只是**概念阶段推荐**，置信度为**中**。没有任何候选经过灰盒或玩家测试，不能据此自动通过 Gate 1。

## A — 《无人呼救》

### 一句话提案

**把声音扔到墙上，诱导独眼巨人撞毁洞门；你不伤害他，而是让更强的敌人按你的谎言行动。**

### 玩家承诺

- 身份幻想：不是勇士，是困在巨人洞中的说谎者与观察者。
- 情绪弧：无力 → 看懂敌人 → 第一次骗过 → 冒险靠近 → 让山一样的敌人替你开门。
- 核心乐趣假设：预测巨人如何解释声音，并在他不可撤销的冲撞中重新布置空间。

### 3–5 分钟结构

| 时间 | 内容 | 只改变什么 |
|---|---|---|
| 0:00–0:20 | 出口被石门封住；巨人聆听；唯一高亮表面发出回声 | 证明投声会改变敌人朝向 |
| 0:20–1:00 | 第一根脆柱与巨人排成直线 | 证明回声可以让冲撞改变空间 |
| 1:00–2:00 | 第二根柱在侧面，需要玩家先移动到可观察位置 | 加入站位，不增加新动作 |
| 2:00–3:20 | 最后一根结构要求在巨人恢复前投声，窗口更紧 | 加入时机承诺 |
| 3:20–4:30 | 洞门开启；玩家穿过门槛；巨人最后一次盲抓 | 兑现逃脱与身份主题 |
| ≤5:00 | 成功/失败结算，5 秒内可重开 | 完整闭环 |

### 玩法设计概况

**对抗**

- 没有 Boss 血条；三次结构撞击是空间进度，不是变相伤害条。
- 投声本身伤害为零。声音只改变巨人的注意、朝向和下一次承诺动作。
- 玩家靠近结构后获得更强落点，但也进入冲撞路径，奖励主动承担风险。

**关卡**

- 单一洞穴、一个出口、三根结构；每一根结构只教一个变量。
- 回声落点、巨人眼/耳朝向、冲撞线、目标结构必须同时可见。
- 高对比对象全部有功能；背景岩块不允许伪装成可投声表面。

**动画**

- 巨人只做 `聆听 → 转向 → 蓄势 → 冲撞 → 受挫/恢复` 五个强剪影状态。
- 冲撞一旦承诺不可瞬间转向；玩家因读懂预备动作而成功。
- 奥德修斯的动作人格是压低、观察、短促投声、确认后移动，不使用通用英雄战吼。

**AI**

- 确定性状态机：锁定最近一次“有效表面回声”，按固定优先级处理可达冲撞线。
- 不用 GOAP、行为树组合搜索、生成式语音或动态世界规划。
- 同一状态和同一输入必须得到同一冲撞目标，方便玩家学习与回归测试。

### 最小灰盒

- 几何：矩形洞穴、胶囊巨人、三个盒体结构、一个出口、回声圆环和冲撞线。
- 首要测试问题：**玩家是否会把声音放到结构后，而不是把它当攻击弹？**
- 通过标准：30 秒内首次有效投声；第二轮前能预测巨人目标；5 分钟内通关或准确解释失败。
- 失败信号：远处等待成为最优；巨人改变目标无预兆；玩家只盯 UI 不看空间。

### 为什么排第一

- **可验证：** 单敌人、少量状态和三根结构即可做出完整因果。
- **判断：** “骗过不可战胜的敌人”比“打败希腊怪物”更保留奥德赛辨识度。
- **信心 ≠ 正确性：** 当前高分来自结构清晰，不证明投声本身手感有趣。若第一次机制 spike 不能让玩家主动尝试第二种落点，应立即降级或淘汰。

## B — 《六盏灯》

### 一句话提案

**自动前行的船夹在六首怪物与吞海漩涡之间；每次拖舵都不是找绝对安全，而是公开选择局部损失或全船风险。**

### 玩家承诺

- 身份幻想：不是全能英雄，是知道坏消息仍必须下令的舵手。
- 情绪弧：寻找安全线 → 发现没有无代价答案 → 承担第一次损失 → 用更好判断保住余下的人。
- 核心乐趣假设：看懂两种威胁的未来状态，在承诺航线前权衡风险，而不是靠反射随机躲避。

### 3–5 分钟结构

| 短句 | 新变量 | 目标 |
|---|---|---|
| 1 | 只出现慢速漩涡吸入区 | 学会拖动并承诺偏航弧 |
| 2 | 只出现一次斯库拉扑击扇区 | 看懂船员灯的位置性风险 |
| 3 | 两者错峰出现 | 第一次做“稳定损一 / 冒险保全”的选择 |
| 4 | 两者部分重叠且船体因既有损失略失衡 | 用前面知识完成最终承诺 |

### 玩法设计概况

**对抗**

- 敌人不被击杀；玩家操纵自己与已公开威胁的关系。
- 斯库拉侧风险是确定的局部损失；漩涡侧是窄窗口的全局风险。
- 允许不同结局等级，但基础成功条件必须在开始时可见，不能通关后才宣布“你本可救更多人”。

**关卡**

- 单一窄海峡用四个短句排列，不做海图和分支岛屿。
- 水面预兆先于危险执行；扇区、吸入环与船的预测弧采用不同且稳定的形状语法。
- 六盏灯在甲板上的位置就是风险信息，不另做抽象队伍列表。

**动画**

- 船体倾斜、灯的摇摆、斯库拉颈部蓄势和漩涡呼吸必须先于判定。
- 船员损失留下空位与节奏缺口，不以数字扣减替代。
- 不做真实流体或布帆模拟；全部运动曲线预制且可调。

**AI**

- 斯库拉按已公开扇区和固定时钟攻击；没有自由目标选择。
- 六盏灯不是六套 AI，只根据位置与全局状态切换少量动作/音色。
- 失败回放可重现同一危险序列，便于玩家验证自己的判断。

### 最小灰盒

- 几何：窄长平面、三角形船、六个光点、两个危险体积、四组时间曲线。
- 首要测试问题：**玩家能否在第一次损失后说清两边的不同代价？**
- 通过标准：10 秒指出出口和两类危险；首轮后说明两侧风险；至少一次知情改变航线。
- 失败信号：持续寻找不存在的无伤线；损失发生在画外；多数失败来自操控惯性而非选择。

### 为什么排第二

- **可验证：** 原典明确给出“不战、逃离、局部损失与全灭风险”的结构。
- **判断：** 它有三个候选中最强的伦理重量和画面，但“明知要损失”也最可能触发抵触。
- **信心 ≠ 正确性：** 选择是否被感为“我的决定”只能靠试玩验证。若玩家认为结果预设，无论视觉多强都应淘汰。

## C — 《夜织伊萨卡》

### 一句话提案

**佩涅洛佩从织物中抽走一根线，立体宫殿随之失去一段路径；你用家园记忆的缺口，换求婚者又走一夜弯路。**

### 玩家承诺

- 身份幻想：归途不仅由远航者完成，也由留在家中、不断拖延崩塌的人守住。
- 情绪弧：掌控漂亮秩序 → 第一次亲手破坏 → 看见敌人改道 → 在家园完整与时间之间取舍。
- 核心乐趣假设：抽走一个二维元素，同时理解三维空间和 NPC 路径的连续变化。

### 3–5 分钟结构

| 夜晚 | 新变量 | 目标 |
|---|---|---|
| 1 | 一根线只对应一条直路 | 证明线与空间的一一映射 |
| 2 | 一根线影响门槛，求婚者会按固定优先级改道 | 证明路径后果 |
| 3 | 关键线同时承载一枚家庭记忆 | 引入真实代价 |
| 4 | 两类求婚者从不同入口逼近 | 综合判断，不增加新动词 |

### 玩法设计概况

**对抗**

- 没有直接战斗；玩家通过删除路径控制时间和接近关系。
- 每晚只允许有限次抽线，防止逐根穷举。
- 胜利要求守住内室且至少保留两枚记忆，避免“把家全部拆掉即可赢”的退化策略。

**关卡**

- 5×5 预制节点图与六根可抽线；不是自由建造或完整塔防。
- 悬停时全程高亮同色线、受影响地面和将改道的求婚者路径。
- 自动复织使用固定顺序，并在夜晚开始前预告；它是环境时钟，不是玩家第二动作。

**动画**

- 线从宫殿连续回卷到织机，墙、路和人物影子按同一方向坍回平面。
- 佩涅洛佩每次抽线都有短暂停顿与不可逆的松手，表现她不是无成本操纵棋盘。
- 求婚者用速度、停顿和抢道表达贪婪/迟疑，不靠长对白。

**AI**

- NPC 只用预制图上的最短路与三条显式优先级；路径变化后立即显示下一目标节点。
- 两种求婚者最多只在“偏好最短路 / 偏好完整图案”上不同。
- 不使用动态世界生成、通用群体 AI 或社交关系系统。

### 最小灰盒

- 几何：5×5 节点、六条彩色样条、四个圆柱、一个内室、四个记忆标记。
- 首要测试问题：**玩家在松手前能否预测一根线会让哪些空间消失？**
- 通过标准：30 秒内有意图抽线；第二夜前口述线—路—改道关系；至少一次为保记忆承担风险。
- 失败信号：只能逐根试错；自动复织像随机撤销；视觉坍缩遮住下一步。

### 为什么排第三

- **可验证：** 基础节点图可测试，不需要真实布料。
- **判断：** 它的主角视角与视觉转化最原创，也最能让“家园为何值得归返”拥有重量。
- **信心 ≠ 正确性：** 线—空间映射是高风险假设。若 10 分钟纸面/交互 spike 仍需文字解释，就应淘汰，而不是继续加高亮、箭头和教程。

## 横向判断

| 决策问题 | 《无人呼救》 | 《六盏灯》 | 《夜织伊萨卡》 |
|---|---|---|---|
| 最强主题 | 机智、身份、以弱胜强 | 归途、领导、不可避免代价 | 等待、忠诚、守住家园 |
| 最可能的第一秒吸引力 | 巨人追随可见回声 | 极小船夹在双重灾难间 | 织物折成立体宫殿 |
| 最可重复的技巧 | 回声落点、站位、冲撞时机 | 风险读取、航线承诺、微调 | 映射预测、路径重构、损失控制 |
| 最大制作变量 | 敌人冲撞与相机 | 船的惯性与公平感 | 线—空间可读性 |
| 最小失败成本 | 低 | 中 | 中高 |
| 当前推荐置信度 | 中 | 中 | 低—中 |

## 建议

1. **若目标是最快得到可信灰盒证据：选 A。** 第一个机制 spike 只验证“投声 → 锁定 → 冲撞 → 空间改变”。
2. **若目标是追求更强情绪代价，且接受公平性迭代：选 B。** 第一个 spike 只验证“公开两种风险后，玩家是否认为损失是自己的决定”。
3. **若目标是优先原创视觉和非英雄视角，且接受先做可读性淘汰测试：选 C。** 第一个 spike 只做二维线与三维路径同步，不做角色和美术。

不要并行开发三个灰盒。Gate 1 的价值就是在实现成本出现前砍掉两个方向。

## 这是我认为你仍然可能错的地方

“奥德赛”未必应该以奥德修斯为唯一中心。若你默认只有航海、怪物与英雄战斗才算主题忠实，会错过佩涅洛佩这条更原创、也更能解释“家为何值得回”的路线。反过来，原创性也不能替 C 掩盖可读性风险；如果映射不能自然读懂，应直接淘汰。
