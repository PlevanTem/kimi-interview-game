# 《千名之海》Previsual Direction v1

状态：`previsual_reference`。这不是 Gate 3 StyleBible，也不是正式资产批准。

## 一句话方向

把归乡做成一座可呼吸的 Web 原生图形剧场：故事书式柔和体块承载动作，深海青到盐金的色域变化承载航程，网页转场只在标题、身份、拆名与传播网络中露面。

## 可用锚点

- 体块：圆角、雕塑感、强轮廓，避免写实碎石噪声。
- 构图：远景大留白，角色只占画面小比例；战斗才收近。
- 材质：哑光盐石、布、木、氧化青铜；发光只给事实与誓名。
- 动画：披风和名线先于粒子；停顿、回弹、拖尾表达力量。
- UI：代码原生文字与矢量线框；生成图不得烘焙文字或按钮。
- 过渡：页面像剧场幕布或航海图层滑入，不在持续战斗中做滚动网页特效。

## 不可用锚点

- 不复制 My Little Storybook、A Short Journey、Bruno Simon Portfolio 的角色、场景、构图、车型、模型或材质。
- 不把上一轮错误上传图片作为参考、训练提示或构图依据。
- 不用电影级 PBR 复杂度掩盖动作可读性。
- 不把生成图自动提升为可生产 3D 模型。

## 预视觉资产用途

`ui-keyframes-v1.png` 用于画面节奏；`storyboard-saltcape-v1.png` 用于叙事镜头顺序；`hero-action-sheet-v1.png` 用于动作语义与轮廓；`modular-asset-breakdown-v1.png` 用于拆件规划；`main-character-lineup-v1.png` 用于角色族群差异。所有文件均为可替换参考，正式模型需重新验证拓扑、UV、骨骼、枢轴、碰撞、LOD 与许可。
