# 《千名之海》DEVELOP 迭代说明 v1

## 已交付

- 浏览器原生标题舞台与静态构建。
- 连续第三人称移动和跟随镜头。
- 观察客符、两种身份声明、守卫教学战、潮门首领战。
- 轻击、身份修正重击、闪避、招架、三条名线与拆名。
- 公开 / 绑定 / 斩断三种战后处置及传播网络预览。
- 操作引导、常驻 HUD、可回看航海册、暂停、失败归因、成功和确定性重开。
- 五张原创预视觉参考与四组可替换代码模型资产。

## 迭代轨迹

1. **范围纠偏**：DESIGN v1 把战斗放在 omitted systems，无法支撑动作冒险。本轮创建 Brief、Gameplay 与 DESIGN v2，把战斗和对应剧情放进早期关卡主路径。
2. **视觉先行但不越 Gate**：生成 UI keyframes、storyboard、主角 12 动作、模块拆件、六角色阵容；全部登记为 `graybox-only / previsual_reference`，没有伪装为最终网格。
3. **模型代码化**：主角、桨刃、誓卫、名线、盐柱、潮门、旗布和归潮号由可替换 R3F 组件组成。高细节集中在轮廓、分层部件、材质对比和动作枢轴，不用无意义面数冒充质量。
4. **第一次浏览器实测**：完整失败反馈可用，但教学招架出现窗口/落点错配。
5. **根因修复**：发现招架结束和敌人命中由两个独立计时器竞争。将命中结果改为 reducer 在预兆期间直接结算；计时器只驱动动作表现。
6. **复测**：9 个规则/角色契约测试、静态构建、手动浏览器完整路线，以及 Playwright 的角色实验室与完整船长路线全部通过；上下文和资产审计通过。
7. **提交前根因修复**：补接 `?lab=character`；把 WebGL E2E 改为独占端口、单 worker；修正截图相对路径并删除错误嵌套目录。没有通过延长战斗窗口来掩盖测试竞态。

## 当前不是完成项

- Gate 2 仍需人类判断战斗是否有趣、身份差异是否可感、是否愿意用另一身份重试。
- Gate 3 尚未开始；没有正式 StyleBible，也没有生产级 GLB、骨骼动画、纹理、声音或字体批准。
- JavaScript 主 chunk 约 1.10 MB minified / 306 kB gzip；五张 PNG 合计约 11.76 MB。进入 Release Candidate 前必须拆包、延迟画册、转 AVIF/WebP 并实测帧时间。

## 最小下一轮

只做 Gate 2 玩法验证：分别走船长与朝圣者，确认玩家能解释青息/金环、守势/名线、身份风险和三种传播后果。若玩家仍把战斗理解为普通削韧加处决，先重做名线与胜后处置，不进入正式美术生产。
