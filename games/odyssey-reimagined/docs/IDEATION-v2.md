# IDEATION v2 — 先设计完整游戏，再裁切 Demo

> 状态：当前有效的 IDEATION。基于 `brief-odyssey-reimagined-v2`；完全重做，不继承旧三案、旧排名或“完整游戏只有 3–5 分钟”的推导。

## 结论

**最值得继续的不是一组彼此孤立的神话关卡，而是一套让身份、款待、名声、船员与神祇债务跨旅程传播的系统。**

推荐进入 DEFINE 的顺序是：

1. **《千名之海》**：以身份、款待契约和传闻为核心的群岛沉浸式模拟 RPG。
2. **《众神记得》**：让玩家的事迹变成下一轮世界规则的神话记忆 Roguelite。
3. **《两岸之间》**：让海上归途与伊萨卡政治互相改写的双岸系统叙事冒险。

三案产品潜力接近，当前没有玩家证据。推荐只代表进入 DEFINE 的优先级，不构成 Gate 1 选择。

## 反驳：放开体量不等于应该做无缝开放世界

最直觉的方向是“希腊群岛开放世界 + 航海 + 怪物 + 装备”。这仍然不是默认答案。

- 无缝地图会把大量预算消耗在移动距离、地形填充、交通和资产密度上，却不保证身份、款待与归乡具有系统意义。
- 《奥德赛》的岛屿更像各有规则的实验室：食莲者改变欲望，独眼巨人破坏款待，喀耳刻改变身份，冥界要求面对代价，斯库拉迫使接受损失。高密度“规则箱群岛”比连续地理更匹配原典结构。
- 完整游戏可以很长，但每段内容必须让既有系统产生新组合；不能用更多海面、装备和支线掩盖核心规则不够深。

因此，本轮允许长流程和多系统，却仍优先选择**路线式群岛**、**跨地点状态传播**和**可重组内容语法**，而不是地图面积。

## 专家视角与判断框架

### Jesse Schell：核心体验透镜

使用问题：去掉希腊名词和美术后，玩家是否仍在经历“用机智改写强者制定的局面，并为归乡承担后果”？[来源：Schell Games](https://schellgames.com/art-of-game-design?trk=public_post_comment-text)

### Sid Meier：有趣决策

使用问题：每个循环是否提供信息、节奏和不可兼得的结果，而不是正确选项与陷阱？GDC 官方摘要明确把决策类别、节奏、信息和反馈列为设计问题。[来源：GDC 2012](https://www.gdcvault.com/play/1016165/Interesting)

### Soren Johnson：主题不是意义

使用问题：系统实际奖励和惩罚什么？若玩家靠反复杀戮、刷取和清图最有效，作品表达的就不是机智与归乡，无论角色名字是否叫奥德修斯。[来源：GDC 2010](https://gdcvault.com/play/1012670/Theme-is-Not)

## 可验证：原典能转成哪些长期系统

| 原典结构 | 可验证事实 | 完整游戏系统命题 |
|---|---|---|
| `nostos` 归乡 | 众神讨论的不只是存活，而是奥德修斯能否完成归乡；忒勒马科斯同时在家中寻找父亲的消息 | “家”应是持续变化的目标状态，旅程越久，归去的对象越可能改变 |
| `kleos` 声名 | 角色通过歌者、传闻和行动获得名声；吹嘘战胜独眼巨人又招致波塞冬长期敌意 | 名声必须同时是权限和债务，且可以先于玩家抵达其他地点 |
| `mētis` 机智 | 奥德修斯反复利用名字、规则、伪装、时机和敌人认知，而非仅靠力量 | 解题空间应允许玩家改写 NPC 对“谁、为何、发生了什么”的判断 |
| `xenia` 款待 | 款待关系决定陌生人的安全、礼物、义务与越界；求婚者以长期滥用款待侵蚀伊萨卡 | 每个岛可以由“主人—客人—证人—越界者”的社会规则组织，而不是任务列表 |
| 诱惑与自限 | 塞壬段落中，玩家式主体主动安排束缚与船员职责，以换取接近危险的机会 | 自我限制可以是主动配置的工具；风险不必来自隐藏概率 |
| 船员损失 | 船员有欲望、违令、恐惧与死亡；归乡不是单人无损通关 | 船员应是会改变决策空间的关系与见证者，不只是资源条 |
| 伪装与认识 | 归乡后身份通过伤疤、弓、婚床、记忆和行为逐层确认 | 终局可以读取整段旅程保存的证据，而不是用过场宣布“你回来了” |
| 神祇干预 | 神祇提供帮助、阻碍、伪装和天气，也对人的行为与关系作出回应 | 神祇更适合做改变规则与压力的“元系统”，而不是普通技能树 |

## 研究转译：哪些成熟结构可借，哪些不能照搬

### 1. 知识可以成为真正的进度

《Outer Wilds》的官方分享把探索驱动力放在好奇心、环境内引导和非线性叙事，而不是显式任务清单；这支持“玩家因为知道一条仪式、航路或身份漏洞而变强”。[来源：GDC 2021](https://www.gdcvault.com/play/1027368/Independent-Games-Summit-Sparking-Curiosity)

不能照搬的是时间循环本身。《奥德赛》更独特的结构是传闻、神意和损失持续积累；除《众神记得》外，其他候选不应强加物理重置。

### 2. 旅程可以自己讲故事，但内容必须有语法

《80 Days》把地图、资源和叙事共同组成会叙述自身的旅程；《Heaven's Vault》则展示了动态线索链、少瓶颈以及错过部分内容仍可推进的结构。[80 Days 来源](https://gdcvault.com/play/1021717/80-DAYS-Post-mortem-Letting)，[Heaven's Vault 来源](https://www.gdcvault.com/play/1025149/-Heaven-s-Vault-Creating)

对本项目的含义不是“写更多分支”，而是让岛屿读取少量稳定状态：身份、誓约、传闻、船员、神祇债务。若每座岛都需要完全独立的变量和脚本，长线结构仍会崩溃。

### 3. 社会关系可以直接生成事件

Nemesis System 的官方幻灯把社会层级视为故事机制；《Wayward Strand》让 NPC 的故事同时运行而非等玩家触发；《Wildermyth》强调程序化角色仍必须保持可信和一致。[Nemesis 幻灯](https://media.gdcvault.com/gdc2016/Presentations/Rouse_Richard_RulesOfTheGame.pdf)，[Wayward Strand](https://www.gdcvault.com/play/1029194/Independent-Games-Summit-The-Secret)，[Wildermyth](https://www.gdcvault.com/play/1027924/Independent-Games-Summit-Session-Getting)

这支持把求婚者、船员、港口主人和歌者做成有目标与关系的行动者。但本轮不推导“需要通用生成式 AI”；可读的有限状态与手工角色锚点更容易建立信任。

### 4. 重复结构只有在世界真正记得时才成立

《Returnal》官方回顾把 Roguelite 世界与分层叙事结合；《Hades》展示了大量状态化神话角色内容，但也暴露出 22,000 多行全配音文本并非轻易可复制的成本。[Returnal](https://www.gdcvault.com/play/1027877/Breaking-the-Cycle-The-Making)，[Hades](https://www.gdcvault.com/play/1026975/Breathing-Life-into-Greek-Myth)

因此，《众神记得》的差异点必须是“玩家主动塑造下一轮读取的称号”，不能只做死后刷新房间和继续加对白。

### 5. 后果数量必须受预算控制

Alexis Kennedy 的官方分享直接讨论有限时间与预算下，多少后果才足够、如何支持玩家自我表达；分支结构研究则指出重汇合或平行路径可以避免树状内容爆炸。[Choice, Consequence and Complicity](https://gdcvault.com/play/1023346/Choice-Consequence-and)，[Branching Narrative Structure](https://www.gdcvault.com/play/1023386/Finding-the-Right-Branching-Narrative)

本轮因此拒绝“每个选择永久分裂一条独立剧情”。后果应优先改变关系、规则、可见证据与可用路径，再由关键章节重汇合。

## 恰好三个候选种子

### 1. 《千名之海》

**一句话：**在由款待规则组织的群岛中，你声明不同身份解决冲突，而每个谎言和背誓都会先于船抵达下一座岛。

- 完整产品：路线式群岛沉浸式模拟 RPG；每座岛是一个社会规则箱，交涉、赠礼、潜行、环境布置、战斗与挑拨共同改变身份事实。
- 长期进度：身份履历、誓约、船员关系、仪式知识和传闻网络，而不是单向攻击力。
- 终局承诺：回到伊萨卡后，世界用伤疤、物件、记忆、关系和行为验证“你是谁”。
- 最大风险：身份成为对话标签；战斗成为最稳定解；跨岛状态爆炸。
- Demo 切片：只做一个港口、两种身份、三方关系和一个离港见证者，验证玩家是否会主动管理可被识破的谎言。
- Demo 不证明：群岛耐久度、完整航海、战斗平衡与长线身份连续性。

### 2. 《众神记得》

**一句话：**每次失败的归航都会被歌者压缩成一个称号，下一轮的众神、怪物与船员按这个故事改变规则。

- 完整产品：神话记忆 Roguelite + 船员策略；玩家不只接受随机词条，而是通过行为和叙事权主动塑造下一轮世界。
- 长期进度：海图知识、称号词库、神祇解释权和跨轮角色关系；称号同时提供机会与麻烦。
- 终局承诺：在“被永远传唱”与“真实回家”之间做系统性选择。
- 最大风险：像 Hades/Returnal/FTL 的组合换皮；称号压缩行为时破坏玩家信任；响应内容乘法失控。
- Demo 切片：制作两次相邻航程，让第一轮行为生成一个称号，并在第二轮产生一项优势与一项风险。
- Demo 不证明：几十轮的新鲜度、完整程序生成、长期经济和大规模文本成本。

### 3. 《两岸之间》

**一句话：**海上归途与伊萨卡政治共享同一组誓约、信物和传闻，你在一岸节省的时间会成为另一岸失去的人。

- 完整产品：奥德修斯、佩涅洛佩与忒勒马科斯构成双岸并行系统；NPC 事件继续运行，跨岸结果延迟抵达。
- 长期进度：关系、合法性、共同秘密、传递中的信物和已确认事实。
- 终局承诺：归乡不是单人抵达，而是三条行动链共同决定伊萨卡是否仍是可被认出的家。
- 最大风险：玩家偏爱一侧；延迟反馈不可读；双线内容与测试矩阵昂贵。
- Demo 切片：一个双岸章节、各三项事件、三种跨岸状态和一次必须放弃一侧收益的时间选择。
- Demo 不证明：长篇节奏、角色内容量、完整分支成本和大规模战斗。

## 跨候选设计约束

1. **世界只记有限但有用的事实。** 优先记名字、誓约、见证、船员存亡、神祇债务与关键物件；不追求记录每句话。
2. **每次收益都留下可见代价。** 获得权限可能增加证据，得到名声可能招来神祇，节省航程可能失去关系。
3. **战斗必须改写关系和叙事状态。** 若战斗只产出经验与掉落，它会成为独立于主题的刷取系统。
4. **移动不是空白时间。** 航线选择应改变信息、见证者、时间或神祇压力；否则直接压缩航行。
5. **NPC 不等待玩家。** 关键角色需要目标、时间和少量可读行为倾向，但不推导出通用生成式 AI。
6. **最终认识读取全程。** 回家是否成立，应由玩家保存或破坏的具体证据决定。

## 淘汰与保留判断

- **淘汰神话 Boss Rush 作为完整产品。** 它可以贡献高质量章节，却缺少跨旅程的身份与代价系统。
- **不淘汰动作玩法。** 动作可以是局部解决手段，但必须与见证、伤势、船员和声名相连，不能成为无后果的主循环。
- **暂不选无缝开放世界。** 这不是因为 Demo 做不完，而是当前没有证据表明连续地理比高密度规则箱更能服务体验承诺。
- **暂缓多人船员。** 原因是当前受众假设为单人，且协作会把体验焦点从身份与长期后果转向沟通执行；这是产品定位问题，不是短 Demo 问题。
- **保留知识探索、船员策略与身份潜行。** 它们分别成为三个候选的系统层，而不是单独占据 Gate 名额。

## 判断、未知与失败信号

### 可验证

- 原典确实反复组织归乡、声名、款待、伪装、船员代价与认识过程。
- 引用的 GDC 页面确实把知识探索、动态旅程、社会系统、重复叙事和选择预算作为设计主题。
- 三案已分别写出完整产品结构和局部 Demo，未重新引入统一时长。

### 判断

- “跨地点持续状态”比“复刻著名遭遇”更能形成独特完整游戏，这是设计判断，不是来源结论。
- 《千名之海》当前排第一，主要因为身份、款待、传闻与归乡能共享同一套规则，而不是因为它的 Demo 更容易。
- 《两岸之间》可能拥有最强作品性，但受众理解成本和制作不确定性也最高。

### 信心不等于正确性

- 分数没有市场、可用性或灰盒数据；91.80 与 91.20 的差异不具有统计意义。
