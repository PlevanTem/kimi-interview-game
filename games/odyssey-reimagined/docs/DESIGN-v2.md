# 《千名之海》DESIGN v2 — 盐岬港动作垂直切片

状态：实现中 graybox / previsual。Gate 1 已锁定；Three.js + R3F 已获 Tech Fit Lock；Gate 2 与 Gate 3 尚未通过。

## 结论

本次 Demo 不是角色选择器，也不是 3–5 分钟完整游戏。它必须交付一个能正常完成的早期动作关卡：玩家观察证据、声明身份、学习战斗、击败潮门誓卫、处置被拆出的名字，并看到这件事如何进入传播网络。

本设计采用 Robin Hunicke、Marc LeBlanc 与 Robert Zubek 的 MDA 视角检查：机制是招架、守势、名线和身份修正；动态是玩家在攻击、避让与暴露事实之间权衡；审美结果才是“归乡者用动作重写世界如何称呼他”。如果战斗结束后身份和传闻没有变化，战斗即判定为设计失败。

## 1. 体验支柱

1. **可呼吸的图形剧场**：宽画幅、低界面噪声、强轮廓、柔雾与少量发光名线。网页式转场只用于标题、教程、身份和传播层；持续战斗保持稳定第三人称可读性。
2. **动作就是叙事语法**：轻击破势、闪避保命、招架抽名、拆名定性。敌人不是血袋，而是由角色、空间职责和誓约组成的动作问题。
3. **身份有机械后果**：船长重击更强但失败会留下“武力索船”；朝圣者闪避更自由但主动攻击会破坏公开身份。
4. **胜利必须承担**：公开、绑定、斩断不是结尾文案，而是三条不同的下一岛权限和风险。

## 2. 早期关卡流程

### 2.1 色域朝圣 / 标题舞台

- 一叶船在深海青平面上接近盐金岛影。
- 移动鼠标或方向键让船和潮纹产生轻微偏转；“进入盐岬”是唯一主行动。
- 目的：让 Web 页面进入游戏的过程本身像一次航行，不用传统主菜单墙。

### 2.2 盐滩苏醒 / 安全教学

- 玩家获得移动、宽距跟随镜头和观察脉冲。
- 断裂客符、被扣的归潮号和远处潮门构成三点视觉路径。
- 按 F 观察客符后才开启身份选择；在此之前不推进敌人。

### 2.3 客门声明 / 身份教学

- 船长：重击守势伤害 +1；招架失败会被 Thaleia 记录为“武力索船”。
- 朝圣者：闪避后的呼吸恢复更快；主动轻击会产生“持武朝圣”矛盾。
- UI 必须并列显示“现在能做什么”和“以后会被怎么核对”。

### 2.4 守卫教学战

- 锁定、轻击、重击、闪避、招架按顺序在实际压力下教学。
- 青色吸气 + 武器回收：可招架；金环扩张：不可招架。
- 成功招架暴露第一条名线“守门者”；守势归零后守卫退场，不要求处决。

### 2.5 潮门誓卫

- 第一阶段：慢速突刺和横扫，建立读招。
- 第二阶段：金色环击与布锚扇区迫使换位。
- 第三阶段：守势恢复，必须用连续招架拉出“守门者 / 守誓者 / 无客之主”三条名线。
- 守势清空且三线齐备后按 R 拆名，进入冻结构图。

### 2.6 名字处置与离港

- **公开**：港口共同见证违背客礼；下一岛获得证人欢迎，但权势家族敌视。
- **绑定**：誓卫欠玩家一次通行；下一岛可调用守卫债务，但必须兑现。
- **斩断**：无人能确认开门者；下一岛隐匿抵达，但失去公开客权。
- 玩家从传播网络看到 Thaleia、Ion、Doro 与三座远岛的可交互节点，再登船完成 Demo。

## 3. 战斗规格

### 3.1 玩家动作

| 动作 | 输入 | 承诺 | 规则效果 | 视觉效果 |
|---|---|---:|---|---|
| 轻击 | 左键 / J | 低 | 守势 -1，三段连击 | 桨刃青白拖尾 |
| 重击 | E / K | 高 | 守势 -2；船长额外 -1 | 先收束披风，再盐金冲击 |
| 闪避 | Shift / Space | 中 | 短位移与无敌窗，呼吸 -1 | 身体压低，披风如帆翻面 |
| 招架 | 右键 / L | 精准 | 抵消可招架攻击、硬直、名线 +1 | 画面短停，青线从面具拉出 |
| 锁定 | Q | 低 | 镜头收近并面向最近敌人 | 目标脚下细环，不加准星墙 |
| 观察 | F | 无 | 显示事实载体和敌人誓名提示 | 世界降饱和，事实保留色彩 |
| 拆名 | R | 条件 | 守势为零且名线=3时进入处置 | 三线围成可读三角 |

### 3.2 时间与判定

- 固定步长规则模拟，视觉插值与规则状态分离。
- 规则窗口与预兆绑定：青色吸气可见期间按招架即由 reducer 结算；金环扩张期间按闪避同理。420 ms 动作计时只驱动姿态与保护表现，不再与攻击计时器竞争决定规则结果。浏览器自动化发现计时竞态后采用这一方案。
- 轻击有效帧 120 ms；重击蓄力 420 ms；闪避无敌窗 220 ms。
- 伤害和守势变化由 reducer 记录；动画不得直接写生命值。
- 敌人攻击必须先发出形状 + 动作 + 音高三重预兆，不允许仅凭颜色判断。

### 3.3 失败反馈

- 显示最后一次攻击是“可招架突刺”还是“不可招架环击”。
- 给一个可行动提示，例如“过早收起招架”或“金环必须闪避”。
- 保留身份和传闻预览，但重开恢复固定种子，便于立即验证另一种选择。

## 4. 关卡与镜头

- 关卡由盐滩、客门桥、守卫庭和潮门圆场四段串联，空间逐步收束。
- 视距用弧形盐柱与布旗控制，不做写实大城市。
- 探索镜头距离 9–11 米、俯角约 18°；战斗镜头距离 6.5–8 米。
- 锁定时以敌我中点为目标，限制横向旋转速度，优先保证脚下安全区可见。
- 碰撞使用简单体积；高细节只属于可见模型，不进入碰撞网格。

## 5. AI

- 教学守卫：`WATCH → APPROACH → TELEGRAPH → STRIKE → RECOVER → STAGGER → RETREAT`。
- 誓卫：同一 FSM 增加 `RING_TELEGRAPH`、`CLOTH_ANCHOR` 和阶段条件。
- AI 只读取距离、玩家状态、冷却、守势和阶段；不读取隐藏的玩家输入。
- 敌人每次只承诺一个可读动作；同一错误连续两次后延长恢复，而不是暗中降低伤害。

## 6. 角色动画与拆件

主角动作表预先定义 12 个姿态：中立、警觉、走、跑、跳起、攀越、侧闪、轻击一、轻击二、重击、招架、拆名。当前代码模型使用独立的头、躯干、上/下臂、腿、披风、桨轴、桨刃和名线枢轴。正式骨骼替换时保持动作语义和插槽名，不要求复刻预视觉图的拓扑。

核心拆件：

- 桨刃：木桨、青铜刃、轴、握把、缠带、线轴、誓符。
- 客符：左右盐陶片与青铜销。
- 船印：底座、印章、盖、发光芯。
- 誓卫：面具、冠脊、颈甲、甲片、潮门刃、三枚誓环。
- 布锚：盐石座、青铜轴、棘轮、旗布、发光结。
- 港口：拱、柱、阶、桥、矮墙、潮门、船体、桅杆、帆、舵。

## 7. UI / UE

### 常驻信息

- 左上：一句当前目标。
- 左下：生命盐片、呼吸结、身份徽记。
- 顶部：首领守势和三条名线，仅战斗出现。
- 中下：当前动作教程，完成后缩成操作提示。

### 可回看面板

- `?` 或右上按钮：完整操作。
- `Tab`：身份履历 / 人物关系 / 传播网络三页签。
- `Esc`：暂停、继续、重开、镜头摇动开关、高对比预兆。
- 画册页只展示 previsual reference，并明确“非最终模型 / 非 Gate 3 批准资产”。

### UE 规则

- 教程不遮挡角色与敌人脚下区域。
- 任何新系统第一次出现前先讲意图，再给按键。
- 可交互物同时用距离、轮廓与短提示表达，不用常驻发光边框污染画面。
- 鼠标与键盘以外保留屏幕动作按钮，便于测试和无记忆操作。

## 8. 美术与技术美术边界

参考方向只抽取三类可观察特征：故事书般柔和体块、短旅程式远景与色块导航、互动作品式网页过渡和微动。不得复制参考作品的角色、场景、构图或资产。

当前视觉令牌：深海青 `#082e33`、盐白 `#eee1c5`、潮青 `#53d8cf`、日落赭 `#d99a4e`、誓金 `#f0c36a`、危险朱 `#d96852`。材质以哑光盐石、织物、风化木与氧化青铜为主；高光只服务于可招架窗口、名线和船印。

这是 previsual direction，不是正式 StyleBible。Gate 2 前只验证玩法可读性；Gate 3 前不批准最终模型、纹理、字体和声音。

## 9. 验收和失败信号

必须通过：完整循环、两场战斗、三种处置、身份差异、暂停冻结、确定性重开、操作可回看、静态构建。

失败信号：玩家只会乱按轻击；分不清金环和青色吸气；不知道招架为何产生名线；胜后选项只像文案；身份对战斗无感；教程必须靠开发者口头解释。出现任一项时，不进入 Gate 3。
