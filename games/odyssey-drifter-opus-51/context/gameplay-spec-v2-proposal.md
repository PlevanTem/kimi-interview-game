# 《光线之上》玩法与完整交互改造提案 v2

状态：Gate 2 退回后的待批准提案，尚未实现。  
目标：先证明玩法与交互值得继续，再进入 Visual Lock。  
技术边界：本规格只定义能力需求，不新增或重选框架。

## 1. 结论：从“画线跑酷”改成“共织机关谜题”

一句话目标：

> 用一条光线同时铺路、传力和导光；让阿迦亲手操作机关，在有限线长内把城市的一间间断层重新接通。

旧版的有效决策近似“从当前光头画到下一平台，然后等待阿迦跑完”。v2 不增加技能键，而是让同一条轨迹同时决定三个可见结果：

- **路径**：阿迦会沿哪一段走、停在哪里。
- **力**：哪一段绷紧，能否拉动绞盘、抬起门或稳住平台。
- **光序**：脉冲按线经过装置的先后顺序传播，决定哪些棱镜先被点亮。

思考来自“怎样布置同一条线”，不是来自记忆隐藏阈值或等待 ±145ms。

## 2. 保留、删除与重建

### 保留

- 唯一主动作：按下起点 → 拖动织线 → 松开提交。
- 光线留下玩家手势痕迹。
- 阿迦作为同行者和反馈主体。
- 失败快速回到当前房间可解状态。
- 形状、运动、声音三重反馈，不依赖颜色。

### 删除

- 删除“保持片刻 / 看踏线 / 随脚步松开”和同步窗口；节奏改由动画和关卡呼吸承担。
- 删除标题页与快捷键中的“点击模式 / 长按模式”区分；当前版本只保留直接拖线。
- 删除 40 秒自动实机演示与六张重复微演示；它们说明了规则，却没有让玩家通过操作发现规则。
- 删除 Gate 2 版本的无尽回响；它放大重复内容，不能证明核心乐趣。
- 删除随机生成的 23 段路线；Gate 2 改为五间手工验证房，确保每题有明确命题。
- 删除只显影但不参与玩法的主视线记忆物；叙事物必须被阿迦触碰、携带或用于机关。

### 重建

- 三类功能装置：绞盘、棱镜、阿迦踏座。
- 可见的线长预算、装置状态与因果预览。
- 完整标题、设置、暂停、失败、成功和重试流程。
- 第一房内生教学和按需三级提示。

## 3. 一个动作，三个系统结果

### 3.1 起线

每房只有 1–3 个合法起线点：城市光源、上一条有效线的末端、阿迦手中的灯。按下合法点时，所有本房可作用装置短暂响应；按错时不进入绘制，仅让最近合法点扩张一次。

### 3.2 织线

拖动时实时计算：

- 剩余线长，以卷轮收缩表达，不显示抽象货币数字。
- 每段张力，以粗细、弧度和抖动表达。
- 脉冲经过装置的顺序，以 1、2、3 的小型光痕标记。
- 阿迦将要停留或操作的位置，以身体预演和地面影子表达。

### 3.3 提交

松开只在“接入有效终点或装置”时提交；否则线立即回收，不扣资源。提交后世界在 2–4 秒内完成反馈：脉冲传播、机关动作、阿迦移动或失败点显现。玩家不需要保持按住，也不需要等一个不明确的拍点。

### 3.4 接续

阿迦抵达踏座、绞盘或棱镜后会停下并操作它；他手中的灯成为下一合法起点。玩家仍然只做同一种拖线，但上一笔改变了下一笔的拓扑条件。

## 4. 三类装置与阿迦的真实互动

### 绞盘：张力传递

- 线绕过绞盘并被绷紧时，绞盘转动，门或平台移动。
- 太松：绞盘不动；太紧：固定销开始拔出，预览阶段即可看见风险。
- 阿迦到达后会抓住把手并用身体压住回弹，玩家才能从他手中的灯继续下一笔。

### 棱镜：顺序传光

- 脉冲按轨迹经过棱镜的顺序传播。
- 不同顺序改变桥、门和危险场的开闭，而不是给分数加成。
- 阿迦可推转一枚棱镜；他的朝向和手势展示转动后的出光方向。

### 阿迦踏座：伙伴成为机关

- 阿迦站上踏座后，门只在他保持施力时打开。
- 玩家必须利用他当前的位置，从他的灯接续下一条线；如果先把他带走，踏座释放，门关闭。
- 阿迦不是被动钥匙：他会先看门、再看踏座、最后回看玩家，形成可读的三段意图提示。

## 5. 五间房的认知阶梯

总时长目标 4–6 分钟；每房只新增一条规则，最终房组合全部规则。

### 房 0：线会让世界行动（20–35 秒）

只有一个起点、一个绞盘和一道门。玩家绕过绞盘连接出口，门抬起，阿迦走过去并回头拉紧线。无失败、无线长压力、无文字弹窗。

验证：玩家能说出“线不是路标，它会拉动东西”。

### 房 1：同一条线要同时能拉、也能走（35–55 秒）

绞盘需要一段紧线，但阿迦脚下需要一段有下垂的安全线。全直线会拉开门却使通路断裂；全松线能走却拉不动门。

验证：玩家需要在一条轨迹里制造两个不同张力区段。

### 房 2：顺序就是解法（45–70 秒）

加入两枚棱镜。先点亮上方棱镜会关闭阴影场，再点亮出口棱镜；反向顺序会被阴影吞掉。错误顺序在提交前以脉冲编号显示，提交后得到对应世界反馈。

验证：直连终点失败，但玩家能从装置状态解释原因。

### 房 3：阿迦是另一半（55–80 秒）

阿迦必须先沿第一笔抵达踏座并压住门；玩家从他手中的灯起第二笔，经棱镜到出口。带走阿迦会让门关闭，因此解法要求理解他的持续动作状态。

验证：玩家主动利用阿迦的位置，而不是等待他沿线跑完。

### 房 4：开放组合题（75–110 秒）

一个绞盘、两枚棱镜、一个踏座、一道阴影场。存在两种合法解：

- 短解：线长省，但绞盘张力容错低，需要阿迦先稳住固定销。
- 长解：多绕一枚支点，线长接近上限，但状态更稳定。

验证：玩家能比较两种方案，并说明自己的选择；固定“永远画向下一平台”的自动策略通过率必须低于 20%。

## 6. 首次 30 秒教学

0–5 秒：镜头依次聚焦封闭门、绞盘、阿迦和唯一发光起点。  
5–12 秒：玩家按下起点；绞盘把手轻微响应，出口门沿受力方向抖动。  
12–20 秒：玩家拖过绞盘；线段变紧，门随拖动幅度实时抬起。  
20–26 秒：松开；脉冲沿线传播，阿迦立刻通过。  
26–30 秒：阿迦抓住绞盘回头看玩家，下一起点在他手中亮起。

5 秒无输入：起点扩大，不出现文字。  
10 秒无输入：阿迦看向绞盘并触碰把手。  
18 秒无输入：显示一句“让光线绕过绞盘”。  
请求提示：只显示下一步关系，不画完整答案。

## 7. 完整产品体验流程

### 标题

- 继续（有房间检查点时）/ 开始新旅程。
- 玩法说明：一页控制图，只说明“按下—拖动—松开”和三类装置图例。
- 设置。
- 制作名单。

不在标题页平铺无障碍快捷键，不展示“实机演示”，不展示点击模式切换。

### 游戏内 HUD

信息优先级只有四层：

1. 当前房间目的，例如“让阿迦压住踏座，再点亮出口”。
2. 世界中的装置状态：开/闭、受力方向、脉冲顺序。
3. 指针附近的当前线状态：可提交、线长不足、装置顺序冲突。
4. 右下角轻量操作：拖线、右键撤销、Esc 暂停。

不显示距离、同步链、借锚数等与解题目标无关的统计。

### 暂停

- 继续。
- 重开本房。
- 玩法说明。
- 设置。
- 回到标题。

### 设置

- 主音量、音乐、效果音。
- 高对比、减少动态、字幕/文字提示。
- 全屏。
- 恢复默认。

替代输入只有在真实无障碍测试证明必要时再加入；不得以快捷键切换的实验功能占据核心界面。

### 失败

失败先冻结在具体原因 0.8 秒：断点、错误棱镜或释放的踏座获得唯一高亮。随后出现“重试本房 / 查看提示 / 回到标题”。重试必须在 1 秒内恢复到房间初态，不回放长动画。

### 成功

显示完成时间、重试次数和采用的解法类型；提供“再解一次 / 回到标题”。Gate 2 版本不提供无尽模式。

## 8. 状态机与非法恢复

- `TITLE` → `ROOM_INTRO`：开始或继续。
- `ROOM_INTRO` → `READY`：镜头完成 2–3 秒的因果扫视，可点击跳过。
- `READY` → `WEAVING`：从合法起点按下。
- `WEAVING` → `READY`：取消、无合法终点或指针离开窗口；草稿回收。
- `WEAVING` → `RESOLVING`：提交合法线。
- `RESOLVING` → `READY`：机关改变但房间未完成，开放新的起点。
- `RESOLVING` → `ROOM_SUCCESS`：出口条件满足且阿迦抵达。
- `RESOLVING` → `ROOM_FAILURE`：进入确定性无解或阿迦坠落。
- 任意可玩态 → `PAUSED`；恢复时回到原态，不重放提交事件。
- `ROOM_FAILURE` → `ROOM_INTRO`：重开本房。
- 最终 `ROOM_SUCCESS` → `RUN_SUCCESS`。

非法事件处理：重复 pointer down、无起点 release、失焦、缩放和设置切换都不得推进谜题；恢复后设备状态、阿迦位置、线集合和提示层级必须来自同一房间快照。

## 9. 确定性与能力需求

- 房间采用手工状态图，不在 Gate 2 使用随机生成。
- 相同房间版本、轨迹采样和输入顺序必须产生相同装置状态。
- 引擎需要支持曲线与装置碰撞、分段张力、脉冲顺序、有限状态装置、房间快照、2D 角色动作混合和可访问性设置。
- 测试钩子必须能直接读取：房间、装置状态、阿迦动作、线长、脉冲顺序、失败原因和提示层级。
- 技术负责人应在实现前用“一条线同时拉绞盘并经过棱镜”的最小 spike 复核现有 Canvas 2D 路线是否仍合适；本提案不替代 Tech Fit 决策。

## 10. Gate 2 验收

工程事实：

1. 开始、首房教学、五房游玩、暂停、设置、失败、重试、成功和回到标题全部可达。
2. 固定直连策略在五房中的通过率低于 20%；最终房至少有两种合法解。
3. 每个失败都能定位到具体装置或线段，不使用隐藏阈值。
4. 阿迦至少三次以抓、推、压或携带改变机关状态。
5. 标题、玩法说明和 HUD 中不再出现“点击模式 / 长按模式”“保持片刻 / 看踏线”。
6. 首房从开始到第一次“线改变世界”不超过 30 秒。

用户直测问题：

1. 第一房后，你是否能说出线除了铺路还能做什么？
2. 房 1–4 是否至少有两次需要停下来思考，而不是直接连到出口？
3. 每次阿迦动作是否都与当前机关有可见因果？
4. 失败时是否知道哪个对象导致失败以及下一次怎么改？
5. 标题、设置、暂停、提示、重试和成功流程是否完整且直观？
6. 最终房两种解是否形成真实取舍？
7. 这版是否值得进入 visual-director？

只有用户明确批准第 7 项，Gate 2 才通过并允许开始 StyleBible 与正式资产设计。
