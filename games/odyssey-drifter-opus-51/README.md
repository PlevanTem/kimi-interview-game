# 光线之上：共织之城

五房间程序化机关谜题。你画的不是通往下一个平台的路线，而是装置之间的因果：
路径决定阿迦去哪，曲线松紧决定能否传力，经过机关的顺序决定光会先唤醒什么。

## 一键运行

双击同目录的 PLAY_OPUS_51.cmd，脚本会启动本地服务器并打开浏览器。

也可以在仓库根目录执行：

    node games/odyssey-drifter-opus-51/serve.mjs 5183

然后访问 <http://localhost:5183/>。直接双击 index.html 也能运行，但推荐本地服务器。

## 操作

- 从发光起点按住鼠标或触控，拖出连续光线，松开提交。
- Esc 暂停，R 重开当前房间，H 直接显示当前阶段的完整答案路线。
- 标题与暂停页都可进入玩法说明和设置。
- 设置包含主音量、音乐、音效、字幕、高对比度、减少动态与全屏。

游戏会自动保存当前房间、阶段、尝试次数和设置。

点击场景底部的“需要一点启发？”或失败页的“给我提示”，会直接显示可描摹的金色虚线答案、方向箭头和机关顺序；进入下一阶段后自动收起。

## 五房结构

1. 风井初醒：经过绞盘再到出口，证明线能改变世界。
2. 双息廊桥：绞盘前绷紧，后半段下垂成桥。
3. 折光庭：先静影棱镜，再越过阴影并点亮出口。
4. 守门人的手：让阿迦先站住踏座，再从他手中的灯继续第二笔。
5. 城市心室：完成踏座、绞盘、双棱镜与终灯；短路和经过支点的长路都成立。

旧版点击模式、节拍等待、随机 23 段、重复实机演示和无尽模式均已删除。

## 代码结构

- src/puzzle-v2.js：五房数据、路径命中、机关顺序、阴影、张力、预算与运行状态。无 DOM/Canvas 依赖。
- src/studio-v2.js：单一拖线输入、阿迦动作、程序化场景、粒子、WebAudio、保存和完整产品状态。
- index.html：标题、HUD、说明、设置、暂停、失败与结局。
- tests/puzzle-v2.test.mjs：新版机制与路线测试。
- tests/browser-smoke.mjs：真实浏览器鼠标首关与完整七阶段冒烟测试。
