# 光线之上 · Above the Lightline

浏览器动作小品。你按住、移动、随他的脚步松开，把一条会承重的余光交到阿迦脚下。

- **线形是空间**：穿过哪些锚点，决定他走哪条路。
- **张力是运动**：松线承接，稳线奔跑，紧线弹射，过载则断裂。
- **松开是节拍**：踩上他的脚步拍松手，线会更结实，他会更快。

零依赖，零资产文件。天空、五层城市、平台、角色骨骼、布料、粒子与全部音效
都在运行时由代码生成。

---

## 运行

**最简单**：双击 `index.html`。（用的是经典 `<script>` 标签，`file://` 下可直接打开。）

**带热更新的本地服务器**（推荐，关闭缓存）：

```bash
node games/odyssey-drifter-opus-51/serve.mjs 5183
```

然后打开 <http://localhost:5183>。

目标环境：桌面浏览器，1280×720 起，Chrome / Edge / Firefox 当前版本。

## 操作

| 输入 | 作用 |
|---|---|
| 按住左键 | 抓住发光的**光头**（断口 / 阿迦 / 线尖） |
| 移动 | 塑形；靠近锚点会自动借锚 |
| 松开 | 提交曲线并发出脉冲；踩在他的脚步拍上 = **同步** |
| 右键 | 取消尚未提交的曲线 |
| `空格` | 键盘等价的按住 / 松开 |
| `Esc` | 暂停 &nbsp;·&nbsp; `R` 重开 |
| `T` | 点击切换模式（无障碍等价输入） |
| `H` 高对比 &nbsp;·&nbsp; `C` 减少动态 &nbsp;·&nbsp; `M` 静音 |

**读画面，不是读 HUD**：他会用脚尖敲两下告诉你窗口开了，用后仰告诉你线太紧，
用前伸告诉你线太松，用张臂碎步告诉你他要掉下去了。

## 不想读字？让它演给你看

标题页有两个入口：

- **实机演示** — 约 40 秒，六步。它不是录像：幽灵指针走的是和你完全相同的输入路径，
  跑在真实关卡与真实承重规则上，最后一步还会**故意**画坏一条线，
  让你亲眼看到起毛、断裂、坠落和回溯。随时点击画面或按空格即可接管。
- **玩法说明** — 六张卡片，每张配一个实时跑的微演示（不是插图），
  外加完整的操作与无障碍对照表。暂停页也能打开。

## 玩法要点

- 线越长越重。`容量 = 1000 + 借锚 × 420 + 同步 × 240`；过载的线会起毛，
  并在**松开之前就画出断裂位置**。
- 断了不一定死：他会带着速度变成抛射体，可能被下一条线接住。
- 坠落不是读档。时间与光线一并收回，并且一定退回到还留有助跑余量的地方。
- 四个区对应吸气 / 屏息 / 呼气 / 静止；最后需要你**连续 4 秒不输入**。

## 代码结构

```
index.html          页面、CSS、DOM 界面（标题 / 暂停 / 终局）
serve.mjs           零依赖本地服务器（no-store）
src/
  core.js           数学、随机、噪声、曲线几何（纯函数，可 Node 测试）
  rules.js          承重规则：张力 / 容量 / 负载 / 断裂位置（纯函数）
  palette.js        设计令牌与五套色板
  audio.js          WebAudio 程序化音频（足音 / 线鸣 / 脉冲 / 风）
  input.js          归一化输入 + 无障碍切换模式
  backdrop.js       天空、极光、光柱、五层城市、深渊、前景
  fx.js             粒子、辉光合成、后期
  aga.js            阿迦：两骨 IK、跑动周期、Verlet 布料、五类身体提示
  lightline.js      余光：草稿、借锚、提交、起毛、断裂、残痕
  demo.js           实机演示：六步教学，走真人同一条输入路径
  guide.js          玩法说明：六个实时微演示 + 操作表
  world.js          程序化关卡、呼吸位移、锚点、记忆物
  rewind.js         10 秒模拟缓冲与恢复点选择
  game.js           状态机、模拟、导演、HUD
  main.js           启动、界面绑定、主循环
tests/
  core.test.mjs     纯逻辑单元测试（node --test）
  autoplay.js       浏览器内自动驾驶，跑完整条路线取证
  shot.js           推进到指定区段并停在驭线中的一帧，用于截图
```

渲染与规则是分开的：`core.js` / `rules.js` / `world.js` 不接触任何 Canvas API。

## 验证

```bash
node --test games/odyssey-drifter-opus-51/tests/core.test.mjs
```

自动驾驶（需要先起本地服务器，在浏览器控制台执行）：

```js
eval(await (await fetch('/tests/autoplay.js')).text());
autoplay({ maxSpans: 40 });
```

最近一次结果：`ok: true, reason: "reached-ending"`，23 跨，158 m，
22 次同步，最长同步链 18，3 次失稳 / 1 次回溯，模拟时长 174 秒。

> 自动驾驶只证明链路不卡死。**手感、可读性和乐趣必须由人试玩判断**——
> 这正是 Gate 2 还没有通过的原因。
