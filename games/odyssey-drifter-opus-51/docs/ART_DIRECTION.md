# 美术方向（提案，未通过 Gate 3）

这份文件描述**已经实现在代码里**的视觉语言。它是一份提案，不是锁定的 StyleBible。
Gate 3 需要人工批准；在那之前不生产任何正式文件资产，画面 100% 由代码生成。

---

## 1. 三套形状语言（不得增加第四套）

| 语言 | 内容 | 规则 |
|---|---|---|
| **城市骨架** | 五层视差塔楼、平台、断梁、缆线 | 只有硬直角与破碎的水平断口。永远不发光，只挡光。 |
| **余光曲线** | 玩家画的线、脉冲、锚点、记忆残痕 | 只有连续手写笔迹。永远发光，永远是画面上最亮的东西。 |
| **角色轮廓** | 阿迦、外衣、旧灯 | 只有柔软实心剪影。自身不发光，只接受边缘光与灯光。 |

三者互不越界：城市不会长出曲线，曲线不会变成硬边方块，角色不会被粒子糊住。
**这一条是可验证的**：关闭 fx 层，游戏状态依然完整可读。

## 2. 三种主材质

- **雾**：大气渐变。承担全部深度信息，越远越靠近天空色。
- **灰石**：无高光实色块。城市与平台的唯一材质，没有法线、没有反射。
- **发光**：加法叠色。只属于余光、锚点、旧灯与窗光。

禁用：金属高光、贴图纹理、描边卡通线、任何写实材质。

## 3. 色彩令牌

颜色只承担情绪与呼吸相位。**玩法状态一律不靠颜色**，靠粗细、抖动、虚实与形状。

| 相位 | 区 | 天空 | 余光 | 情绪 |
|---|---|---|---|---|
| 吸气 | 起风断层 | 深靛 → 冷青 | `#6fd7ff` | 清醒、开阔、还有余地 |
| 屏息 | 悬压城区 | 墨紫 → 品红 | `#c78bff` | 压迫、悬置、不敢呼吸 |
| 呼气 | 回声桥群 | 暗酒红 → 琥珀 | `#ffab5c` | 温热、迟缓、开始回忆 |
| 静止 | 晨光终台 | 灰蓝 → 苍白 | `#ffeec4` | 空、静、快要天亮 |
| **呼出** | 终局破晓 | 蓝紫 → 暖橙 | `#fff2cf` | 释然 |

相位之间用 2.6 秒插值切换，破晓用 5.5 秒。所有令牌集中在 `src/palette.js`，
Gate 3 通过后可整体替换而不动任何玩法代码。

## 4. 摄影

- **构图**：阿迦始终偏左，为前方的断口留出阅读空间。
- **变焦**：断口越大、速度越快，视野越开（0.42–1.6）。停息时推近到 1.16。
- **前景**：模糊的缆线与断梁，只负责景深，不承载信息，永远压暗不发光。
- **不做**：追鼠标、突然切轴、持续摇晃。震动只在落地、断线、同步时出现，且可关闭。

## 5. 后期

半分辨率辉光缓冲 + 两次加法放大合成（廉价 bloom）→ 暗角 → overlay 颗粒。
颗粒强度随相位变化（0.02–0.07），破晓时最低。减少动态模式关闭颗粒。

## 6. 关键帧（已在构建中出现，可直接截图取证）

1. **首次承重**：起风断层，第一条线接住阿迦，脉冲沿线传播。
2. **单锚摆荡**：悬压城区，线穿过一个公转锚点，阿迦在下沉段加速。
3. **双锚弹射**：回声桥群，末端上翘的紧线把他抛向更高的平台。
4. **记忆慢路**：低平台上的门框在停息时显影。
5. **最终静息**：晨光终台，天亮，灯留在台上。
