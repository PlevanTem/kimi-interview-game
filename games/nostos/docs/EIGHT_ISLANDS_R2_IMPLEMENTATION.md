## 共同要求

- G01：剧情与顺序不变。场景自动测试和八幕触控通关覆盖实际交互、旁白、回忆、暂停、跳过、离岛、结局及重开。测试加速角色定位，不能冒充人工全路线漫游。
- G02–G03：新的房屋/棚廊/船壳使用实际墙段、支承与同源地高；八岛可达性遍历地形和真实装配碰撞。该检查证明存在通路，不证明所有任意方向均无视觉穿插；补充实机和独立几何审查。
- G04–G05：六项环境资产与岸沫均已注册，来源为项目原创、许可为项目所有、批准状态 pending。预算按真实生成几何计算；人物精度没有降低。大场景构件按空间和材质分组，避免所有新增物件合成唯一大网格。
- G06：`runs/run-20260922-eight-islands-r2/before` 为远程主分支基线，`after` 为当前候选，同一脚本、相机和1280×720视口，共24组前后对照。动态风云不能逐像素同步。
- G07：全岛资源循环、画质和触控检查结果见当前run验证记录。桌面性能采样按岛记录，转场耗时单列，不计入游玩帧统计。它不代表真手机验收。
- G08：审阅页同时显示八岛与全部对照，Markdown明确UTF-8；GitHub仅更新实施分支，main与线上发布未改动。

## 已诊断并修正的问题

1. 船头测试误报：旧测试按资产放置原点估算半径，复合模型内部偏移被忽略。改为真实变换后的三角面投影距离，并正确处理垂直面退化成线段；不放宽3m阈值，不移动线索。
2. 伊萨卡门槛：原46cm实体高于玩家地面。取消叠石、改薄石门槛，增加真实装配射线回归。
3. 塞壬缆绳：独立估算端点未接到船体。改取模型表面顶点，测实际接触距离。
4. 塞壬岩体/卡吕普索拱肩：首轮截图显示叠板和悬浮白石。前者重建为封闭连续岩楔，后者改为落地连续暗岩肋；重拍对应实机图。
5. 忘食岸引水：首轮只有平直暗色标记，未证明排水。改为37点采样的真实下坡槽，补出口和地高测试。
