# NOSTOS · 海蚀彩陶史诗：前三幕实现记录

Run：`run-20260906-sea-worn-r1`。实际可运行的视觉候选，不是概念图替代品；Gate 3 / Gate 4 未由人工批准。命令、退出码和证据见 [verification.json](../runs/run-20260906-sea-worn-r1/verification.json)。

## 美术立场

**人和遗物像被海水磨损的彩绘雕塑，世界用完整三维体积承载记忆，只有回忆才成为黑绘。**

“海蚀彩陶史诗”是本轮工作名，继承“盐蚀切面壁画”规则。重点不是进一步降低面数，而是让大切面、真实开口、受力方向和安静留白成为第一眼感知。保留第一人称自由观察、叙事与交互坐标。

- 大形先成立：木板长短有节奏，树冠有空隙，洞口偏心。禁止等距方条、满地碎石与柱梁式洞口。
- 细节有因果：木纤维沿断裂方向，绳结解释连接，陶器有内壁，头盔有可见内侧，篮子有编织间隙。
- 色光服从体积：三阶非PBR着色，收敛轮廓光和盐蚀反差；忘食岸暖砂冷影，独眼岬阴冷暗岩，序章维持黎明蓝。
- 动作只表达呼吸：现实NPC不引入夸张表演；回忆继续由黑绘时间轴承担叙事动作。

## 九项落地归并清单

按真实资产归并，不把此前设想角色当成已有剧情。前三幕只有 `lotus.crewman` 是现实NPC；序章与独眼岬不凭空增加人物。

1. **序章木筏**：七块不同长宽木板，撕裂轮廓、轻微翘曲、搭接高差；横梁、双圈绳结与断丝解释受力。实现：`world/props.ts::wreckedRaft` + `world/sea-worn.ts::carvedBoard`。
2. **刻名船板**：规则盒体改成破边厚板，刻痕抬到实际板面，保留原线索含义与位置。实现：`weatheredNamePlank`。
3. **忘食果园**：三种有限枝势、六组不均匀主枝、更少但有厚度的大叶片；降低裸露树梢，保留低垂果实。35块网格铺石改为11块顺地形断续弧带。实现：`orchardTree`、`game/scenes/lotus.ts`。
4. **留下的水手**：三维多材质polygon人物；跪坐重心、不对称双臂、大衣褶、鼻梁、发帽、眉与胡须形成雕塑阅读。约1.48m高，无骨骼口型；赭肤、麻布、焦木发色、陶红披布归入原家族。实现：`world/lotus-crewman.ts`。
5. **生活遗留组合**：14段空心瓮、侧倒器皿、开口杯与局部黑绘带；火塘块石、灰与焦木；新增有编织空隙、提柄和五枚果实的采集篮，位于原果实线索旁。实现：`abandonedVessels`、`coldHearth`、`harvestBasket`。
6. **弃置头盔**：保留主要轮廓和松开双带，补可见内侧，避免开口像透明外壳。当前为反向内表面，不冒称独立实体壁厚。实现：`abandonedHelmet`。
7. **独眼洞穴**：连续偏心洞壳替代三排重复柱梁，入口一侧低压、一侧高挑；前口、内壁、外壳、后壁建立深度。层岩改宽带大切面，保留原通路和碰撞。实现：`caveMouth`、`stratifiedRock`。
8. **烧硬橄榄木桩**：削尖端、焦黑端、裸露木色刮痕分开阅读；减少小段起伏，在原交互点斜置微抬，主轴指向洞内。实现：`burnedStake`、`game/scenes/cyclops.ts`。
9. **统一表面与现实—回忆过渡**：前三幕 `sculptedStyle=1`；细节采样收窄、rim上限0.22、暗部保留冷反光；进入回忆时显出稀疏刻线，随后环境退成浅底，让黑绘人物主导。既有16张回忆母题和节拍继续使用，不算本轮新制PNG。

## 三组资产、构图、镜头与动画对应

### A · 方向性遗物

木筏、船板、船肋、木桩、柱和绳由主轴与断口建立识别，不能靠高频贴图。斜俯近景看见厚度、开口与搭接；不移动交互点伪造构图。木筏后留空海，木桩沿洞口负形引导视线。静物不动；保留原入岛、凝视和离岛机制，没有把旧方案的全部镜头建议数值硬改进游戏。

### B · 矿物与生活体块

石头、铺石、断柱、陶器、篮、头盔、洞壳共享大面和稀疏缺口。石头三种有限轮廓、平底宽切面；铺石一次倒角；柱身12道浅槽与不齐断顶；陶瓮14段中空截面、缺口和稀疏环带。中景先看庭院/洞口负形，近景再读内壁。全部3D网格，不自带旋转、发光或拾取动画。

新增ID：`game.nostos.environment.sea_rock`，以及 `game.nostos.prop.` 下的 `cut_stone`、`salt_pithos`、`carved_board`、`coastal_boat`、`mineral_column`、`mineral_drum`、`harvest_basket`。通过 `COASTAL_ASSETS` / `NARRATIVE_ASSETS` 查找。

### C · 有机生命与记忆

岸边植被新增 `game.nostos.environment.coastal_leaves`，每簇五枚有厚度的稀疏长叶；树冠让天光，人物位于树下开口而非叶墙上。人物正/侧近景检验轮廓；果园与头盔采用成对镜头，不要求原坐标下同时具有不现实的英雄比例。

叶面shader风摆峰值24mm；水手上身约4mm呼吸，受角色位置半径约束，不是骨骼动画。reduced motion关闭两项。海浪延续原循环，岛内位移衰减防浪峰覆盖洞前低地，保留外海风暴。回忆仍为2.5D黑绘显隐/整体变换，由原时间轴驱动。

## 根因驱动的收敛

首轮去除了重复基本体，实拍仍有树梢裸露、中央光晕和巨幅裂纹。调整为降低主干、偏移太阳、收窄独立天空光晕，没有加装饰填画面。

岩面问题追到盐蚀蒙版：反照率风化虽已收窄，盐层复用裂纹图并向绝对浅色插值，重新放大玄武岩黑缝。GPU只读诊断确认uniform为1且片元源码为新版，排除开关与缓存；最终改低频连续场及相对底色提亮。海浪穿低地来自无限海面未考虑岛内范围，用位移包络修正，不抬地形破坏通行。
