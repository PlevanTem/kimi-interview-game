# NOSTOS 后续六岛环境优化规格 R2

状态：实现前规格。2026-09-22 用户指令“继续完成后续场景的设计优化，列出细粒度的优化项 spec 描述再执行，完成后更新 github”。本次授权覆盖六岛候选制作与 GitHub 实施分支更新，不代表 Visual Lock、手机性能验收或 main 发布。

## 统一实现与验收契约

- G01 保留八幕顺序、所有剧情 ID、文字、人物数量、记忆时间线、结局；优先保留交互坐标。需要变动时模型、触发与镜头必须一起修改并记账。
- G02 建筑必须有厚墙、真实门洞、梁架与屋面承重连续关系；人尺度净门宽 ≥1.8m，主路 ≥2.4m。新墙使用线段碰撞，不能用几个圆近似长墙；不增加跳跃或楼层机制。
- G03 建筑楼地面和路径读取 Terrain 的同一高度函数，基础压入地面；新增台地以缓坡衔接。树、柱、陶罐、灶台不可悬空。
- G04 复用既有海蚀彩陶材质；静态几何按空间/材质合批；每岛新增环境资产上限 20,000 顶点（复杂家宅可 24,000），整岛 <300,000。保留互动人物精度，不以隐藏故事物降低开销。
- G05 每岛资产以 game.nostos.environment.* 注册，经 Narrative Assets 解析器放置；程序生成有确定 seed、来源与预算。共享注册表由主线程串行整合。
- G06 每岛从登岸到全部线索与记忆/离岛点的可达性自动检查；室内入口/记忆视线用几何射线检查。渲染截图覆盖远、中、近三个固定第一人称机位，保留改造前后，不使用概念图作为完成证据。
- G07 全八幕触控回归、低中高画质、重开与切岛资源检查；记录全帧 draw calls、纹理/几何数。桌面结果不能替代 iPhone 13 / Pixel 6 各 15 分钟验收，性能状态继续明确未验收。
- G08 建立八岛可浏览审阅页，中文明确 UTF-8；规格、实现映射、局限、测试命令和退出码写入本 run。推送 codex/nostos-eight-islands，提供 GitHub 审阅入口，不推 main。

## 伊萨卡：偏心树院与完整家宅

- I01 将现有平顶/简块屋改为偏心双坡主屋，厚墙围合原有 x±7、z约-25至-15 的家宅尺度；保留门槛 (0,-16) 焦点。屋面有搭接、檐口、屋脊、支撑梁及端墙，不扩大成宫殿。
- I02 真实中央门洞至少2.4m，室内单层可进入；将原圆墙碰撞替换为墙段，楼面约4.6m与现有庭院接平。入门后的背景可看见储物和生活使用关系。
- I03 围绕原活橄榄树 (-11,2) 形成不对称低院墙，至少两个缺口；不遮挡摸树、骨骸、布、门槛的路线或结局取景。
- I04 东侧小灶间低于主屋，灶床、木柴、器皿台与储藏架相邻；炊烟来源须落在实际烟口附近，不能穿过实心屋顶。
- I05 檐沟接墙边落水口、地面浅槽接蓄水容器；渠道从高到低，水槽出口在可见位置。墙体保留有限的修补面，不加断柱废墟。
- I06 远景：先读树冠、烟、错位屋脊；中景：穿偏心院口看到门廊；近景：门槛及磨损梁柱，保留“普通的家”尺度。

## 忘食岸：半月果园与低棚廊

- L01 减去岛心重复断柱/登岸装饰废墟，以三段转折棚廊构成不闭合半月。棚廊围绕现有果园服务，东侧及人物侧保持开口，禁止对称神殿构图。
- L02 屋檐约2.6m、最高屋脊约3.4m；短跨梁逐段转向，每段有实际承重柱、局部陶土背墙与开口。棚廊地面随场地铺垫，不能让基础露底。
- L03 两处小范围台地/缓坡、低挡土沿和浅引水渠共同表达果园坡向；人物和果实锚点维持可达，根系贴台地，不形成等距树阵。
- L04 棚下设置有腿的晾果架、果实、分组陶罐和低座位，设施之间留操作空间，数量克制；遮阴棚有室内干燥区。
- L05 保留单向脚印、弃盔、冷火与水手的叙事对比；新棚廊不得切断脚印或占据弃盔负形。
- L06 三机位分别读低屋脊与疏冠、穿廊望人、弃盔与果实；保留晴蓝/海青的环境，不将全岛做成黄色滤镜。

## 塞壬水道：斜层岩峡与水流中的船骸

- S01 增强两岸斜向大岩层的错位收口，左右不得镜像；保留桅杆与航道的中央负形。岩层逐步向外削低，洞口不能读成石门建筑。
- S02 将船骸碎片组织成不同搁浅高程的龙骨、肋骨与残甲板，轴向遵循峡道流向；保留原船绳、桅杆与线索位置。
- S03 局部甲板是可理解的步行地面，与岸地缓接；新增不可通行船壳有准确碰撞，至少保留2.4m连续安全路径，禁止隐藏高差陷阱。
- S04 增加低系泊石与受拉缆绳、断端和水线磨蚀；绳索两端连接实体，不能悬空作装饰。
- S05 风口可见有限浪沫/湿痕，背风侧保持稀疏静水表达；新增环境运动采用共享风向，低档减少数量，不增加全屏透明层。
- S06 远景岩层收口，中景绕行船肋产生遮挡变化，近景绳与桅杆关系清晰；声喉是空间形态，不加入超自然巨型雕像。

## 卡吕普索：岩壳内的生活与造舟

- C01 延续已验收过的既有洞居—四泉—草地—望海凹岩布局，不替换人物、衣物、树桩或核心洞壳，不挪动剧情锚点。
- C02 为洞居加可读的内部厚岩壁/拱肩层次；干燥床位、织作处与灶床分区，任何内衬不得挡住人物脸或洞口路线。
- C03 炉床接地，柴架、石案与陶罐凹台共同组成生活设施；高处架子必须有支承，堆物不侵入叙事路径。
- C04 泉水分流口和下坡渠道连贯，饮用取水浅池与造舟空地分开；在已有四泉之上完善岸缘和出口，不制造上坡水。
- C05 造舟场有垫木、料架、木屑/短板分组，以现有斧头与树桩讲清制作流程；不新增随机树桩，不铺满草地。
- C06 远景仍读洞居与草地，中景四泉连接生活/劳作，近景织物或斧柄的尺度不被新建筑抢走。

## 无名之海：退潮岩脊与失重留白

- P01 沿岸三段断续弧形低岩脊，高度0.4–1.2m；朝空海的缺口保留木筏和导星视线。岩脊是海蚀地质，不是人为围墙。
- P02 一段倾斜断船肋最高2.8m，接地/埋沙；漂木按潮流分两组，方向一致而长度不等，不能形成废墟街区。
- P03 两条浅潮沟与岸线汇接、湿暗沉积带贴地，不能是浮在沙面上的蓝色长方体；深度和坡度不阻塞步行。
- P04 禁止新增神殿、居民建筑、密植被、金太阳；保留岛心空白、断桨、木筏与黎明冷光。
- P05 三机位重点是缺口、船肋侧影、绳与磨损木端；前景遮挡不持续占画面15%以上。

## 亡者之岸：空白中的仪式路径

- N01 潮蚀低台地和错位界石形成断续路径，保持至少半数场地为空白；不加冥府宫殿或巨门。
- N02 祭酒浅槽汇向低洼，边沿和出口可见；原祭仪物、人物与记忆锚点不动，路线不是封闭迷宫。
- N03 增加贴地柴堆、靠置桨位与沉积层带，木柴/桨有实际接触支承，不随机撒满地表。
- N04 低雾与弱方向光延续原调性，局部湿润只出现在暴露低处；不可用更亮、更密的装饰消除失落感。
- N05 远景界石中断而海留白，中景浅洼与足下路径，近景祭酒痕与桨位；天空和雾留出层次，不把人物吞没。

## 执行顺序、证据与失败处理

先保存六岛固定机位基线，再制作伊萨卡/忘食岸、塞壬/卡吕普索、序章/亡者之岸。三个无共享写入的实现模块可以分别工作；注册表、布局索引、天候和审阅页面由主线程串行合并。实现者不得改变上述剧情契约。

每一项在完成矩阵中填写实现文件与证据；未满足的规格不得用“代码存在”替代画面/运行证明。发现穿墙、基础悬空、堵交互或资源增长时，记录根因并最小修复后复测。手机真实性能没有设备证据就标未验收，不能宣称工作室级最终放行。
