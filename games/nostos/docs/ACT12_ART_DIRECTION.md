# 第1、2幕 · 环境叙事美术深化

本轮由用户直接要求实施：延续第0幕试点，优化第1、2幕场景和道具3D建模，并本地打开供审阅。不增加黑绘、音效、战斗、拾取、任务列表；不将实现记作人工 Visual Lock。

## 技术与视觉约束

继续使用当前 Three.js / WebGL2、第一人称62°基础视角、米制Y-up、程序化几何、共享 Fresco 壁画着色与静态合批。主验收视口1280×720；不引入外部纹理或模型。每个新英雄资产预算2万顶点，单幕静态布景预算30万顶点；碰撞用少量圆形代理，与天花板网格分离。

沿用方向性长构件 / 侵蚀矿物体块 / 水平层带。材质仍为有机遗物、矿物、海雾三类；仅用既有颜料。避免堆密度、塑料轮廓光、空交互点和同形道具。

## 第一幕：甜蜜的停留

从倒伏酒瓮、宽叶半埋船桨，到只有去程的脚印，再到可透光果树庭院，最后是松开双带的弃置头盔。保留全部原叙事与交互类型。

- 果树改为弯干、外展枝、独立叶簇、低垂果串和根部。果梗由同一枝条曲线取样连接，主树冠高于眼睛。
- 酒瓮有中空壁厚、器口、耳柄与碎陶片，火塘有独立白灰和焦木。
- 头盔侧翻在薄石面上，带子松开；减少“展示台”高度。
- 断柱高度错落，横梁按相邻柱顶真实高程连接；浅石铺按地形逐顶点贴地。
- 随机卵石46→24，避让交互物4m，保留海岸和树后负形。调整光晕、饱和度和颗粒，不改黄昏情绪。

## 第二幕：尺度与代价

羊栏 → 巨骨 → 自己人的盾 → 羊毛痕迹 → 焦木 → 洞内木桩。核心不是新增怪物，而是让环境显出非人的尺度。

- 洞窟由三进岩壳、顶盖和后壁形成深度；中央留下约9m开口，不用圆石堵住核心路线。
- 岩壳使用连续拓扑与克制层理，避免堆叠圆桶的封口亮缝。两侧岬角延续洞口轮廓。
- 地形振幅4.6→2.8、层理隆起3.2→1.8，保留洞前谷地和洞口高台，降低随机丘脊对地标的遮挡。
- 木桩区分橄榄木干、切口与烧硬尖端，低轮廓光避免读成金属标枪。
- 随机石58→26，避让线索4.5m及中央通道。羊栏焦点从空地中心移到可见栏石边缘。

## 资产与编辑入口

`src/world/narrative-assets.ts` 的 `NARRATIVE_ASSETS` 是7件英雄资产的类型化解析入口，场景与 `tools/assets` 调用同一份工厂。资产台增加“六点六、第1、2幕场景与道具”。ID / 材质 / 来源 / 预算登记在 `context/asset-registry.json`。

`stratifiedRock` 另供第二幕参数化岬角与散布岩石使用。石铺、断柱和已有羊栏/骨骸/盾/羊毛保持场景装配层，不建立重复资产副本。

资产台不是游戏后期链：预览单独补一次linear→sRGB编码，避免材质被错误显示得过暗；英雄卡片取消默认figure边距，使用较大画布。该显示适配不进入游戏渲染。

## 本地审阅

运行 `npx vite --config games/nostos/vite.config.ts --host 127.0.0.1 --port 4175 --strictPort`（直接调用Vite，避免PowerShell/npm转发参数被解释为根目录）。
