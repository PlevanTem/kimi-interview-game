# 《归航 · NOSTOS》玩法规格

范式参照《What Remains of Edith Finch 艾迪芬奇的记忆》：
**在半封闭的独立场景里行走，触碰物件触发回忆片段，环境叙事是绝对核心，
辅以少量简短的 NPC 对话。**

---

## 一、允许的动词，只有三个

| 动词 | 操作 | 说明 |
|---|---|---|
| **走** | `W` `A` `S` `D` / 方向键 / 手柄左摇杆 | 2.05 m/s；按住 `Shift`（或手柄左扳机）快跑至 3.6 m/s。没有蹲、没有跳 |
| **看** | 鼠标 / 手柄右摇杆 | 靠近可触碰之物时准星张开成一个细环，下方浮出一行提示 |
| **触碰** | `E` / `Enter` / 鼠标左键 | 触发一段旁白、一段对话，或一段回忆幻象 |

其余按键：

| 键 | 作用 |
|---|---|
| `Shift` | 快跑 |
| `H` | 呼唤引路的光：一串光尘浮起来，指向这一幕下一处该去的地方 |
| `空格` | 跳过当前这段回忆 / 推进到下一句 |
| `Esc` | 暂停（同时看到航程进度与设置，并释放鼠标锁定） |
| 点击画面 | 重新锁定鼠标 |

### 开场引导

第一次点"开始"时，黑场里会有一段引导（八句，不到一分钟），交代三件事：
你是谁（漂了二十年的船长）、你要做什么（走过八座岛，触碰八件东西）、
以及为什么值得做（想起全部，才认得回家的路，也才敢再说出自己的名字）。

这是全作**唯一一次直接对玩家说话**，说完就再也不解释。
按 `E` 或 `空格` 可以逐句推进；从存档继续时不再出现。

### 引路的光（`H`）

原本这部作品一个指引都没有。实际玩下来，在雾里来回找最后一件没看过的东西
会把"漫游"变成"翻找"——于是补了这一个，但守三条纪律：

1. **只在被呼唤时出现**，绝不常驻。不按 `H` 的人玩到的仍是原本那部作品；
2. 它是**世界里的一串光**，从你正前方浮起、再拐向目标，不是屏幕上的箭头；
3. 九秒之后自己熄灭。它带你走一段，不替你走完。

目标按"还剩什么该看"选：先是这一幕没读过的线索、没听过的人、没碰过的记忆物件里
最近的一件；全部看完之后，它指向岸边的船——这也是"怎么进下一幕"的提示。
被指着的那件东西，它自己的微光也会同时亮起来。

## 二、核心循环

一幕 5–10 分钟：

```
登岸        移动锁死，镜头缓慢横摇过整座岛，左下角压出幕卡
  ↓
漫游        雾墙围合的小场景，无地图、无指引、无目标标记，靠地标导航
  ↓
读线索      3–5 处环境线索，每处一两句旁白。不进任何清单，读过就熄灭
  ↓
核心记忆    触碰本幕唯一的记忆物件 → 一两句引子 → 回忆幻象接管
  ↓
回忆幻象    35–85 秒。世界褪成壁画双色，遮幅收窄到 2.39:1，
            黑绘剪影随旁白一层层浮现，说完最后一句碎成颗粒
  ↓
走向船      幻象看完之后，岸边那条船上的微光才亮起
  ↓
硬切        1.8 秒推向过曝白，直接进下一幕
```

线索**不是解谜前置**，也不是收集要素。跳过它们照样能走完全程；
它们存在的唯一理由是：读过之后，那段回忆会打在不一样的地方。

## 三、明确的非目标

这一节是验收依据。以下每一条都**不在**本作范围内，实现时也没有为它们留任何钩子：

- ❌ 海战、实时战斗、连招、格斗动作
- ❌ 伤害、生命值、死亡、失败状态
- ❌ 背包、可拾取物理物件、物理抛掷/堆叠/推动
- ❌ 解谜锁、钥匙、开关、机关
- ❌ 数值成长、技能树、资源管理、经济系统
- ❌ 多结局解算、分支对话、道德值、好感度
- ❌ 收集品清单、成就、地图、指南针、任务栏、常驻目标标记
  （`Esc` 面板展示八幕名称作为航程结构；尚未走过的核心记忆仍不提前揭示）
- ❌ 海量 NPC（全作 4 位）、可招募同伴、护送
- ❌ 巨型无缝开放世界（八幕是八张彼此独立的关卡，硬切相连）
- ❌ 骨骼动画、面部表情、口型（活人在本作里也是黑绘剪影）

代码层面守着这条边界的是 `tests/scenes.test.ts` 里的一条断言：

```ts
it('不存在第五种交互类型——玩法边界写死在数据里', () => {
  expect([...kinds].sort()).toEqual(['clue', 'depart', 'memory', 'talk']);
});
```

想加第五种交互，就得先改掉这条测试——这是一道刻意设置的减速带。

## 四、边界与引导

**边界**：没有看得见的墙，也没有不可见的碰撞盒兜边。
走不出去是因为**再走就是海**——地形在岛半径处降到水线以下，水下不能站人。
雾的密度决定了"半封闭"的视野半径，远处只留地标剪影。

**引导**：没有常驻的任务箭头。四样东西在带路——

1. **地形**：每座岛是一个缓缓抬起的丘，景物一件件从丘背后冒出来；
2. **地标**：断柱、桅杆、洞口、雪松，都放在视线自然落点上；
3. **光尘**：可触碰之物上方浮着一点极淡的光尘，看向它时稍亮，触碰过之后永远熄灭；
4. **引路的光**（按 `H`，见上）：卡住的时候玩家自己呼唤，九秒后熄灭。

四样都长在世界里，不长在屏幕上。

## 五、状态机

```
title ──开始──▶ intro ──说完──▶ arriving ──横摇结束──▶ roaming ⇄ (旁白/对话)
                                          │
                                    触碰核心记忆
                                          ▼
                                       vision ──结束/跳过──▶ roaming
                                          │                    │
                                          │                 走向船
                                    （终章）                    ▼
                                          └──────────────▶ departing
                                                               │
                                                        ┌──────┴──────┐
                                                     下一幕          ended
```

任何阶段按 `Esc` 进入暂停；暂停不改变阶段。

## 六、进度与存档

全作只记两件事：**走到第几幕**，**碰过哪些东西**。

没有数值、没有分支权重、没有结局解算。碰过的东西只影响"这句旁白还播不播"
和"能不能上船"，不影响故事往哪儿走。

`Esc` 面板里的"航程"就是这两件事的呈现：八幕名称始终列出，走过的幕次再补上
对应记忆物件（"亡者之岸 · 空的祭酒碗"），当前幕高亮，未到的记忆物不剧透。
底下一行 `第 X / 8 幕 · 已触碰 N 处`。登岸时的幕卡上也挂着 `X / 8`。

### 走完之后

八段记忆是必经的——每一幕不看完核心记忆就上不了船。所以"全部解锁"
等同于"走完全程"，而终幕会把它一次性还给玩家：

1. 八幕的岛名与记忆物件排成一列，作为这趟旅程的清单；
2. 一句全作一直没说破的话——序章数出的十二条船，到这里第一次结账；
3. 一段关于"他到底变成了什么样的人"的收束。

这是走到这里的人才拿得到的东西，不是奖励道具，是**理解**。
详见 [`WORLDVIEW.md`](WORLDVIEW.md)。

存档写进 `localStorage`；写不进去（无痕窗口、被禁用）就静默跳过，不影响游玩。

## 七、无障碍

| 项 | 做法 |
|---|---|
| 全部叙事有字幕 | 是。字幕大小可在暂停界面 0.8×–1.6× 调 |
| 减弱镜头晃动 | 自动读取 `prefers-reduced-motion`，也可手动开关。开启后步伐摆动、呼吸、手持漂移全部归零 |
| 走不动了怎么办 | 按 `H` 呼唤引路的光；卡住不是设计的一部分 |
| 赶时间 | 按住 `Shift` 快跑；回忆随时可以 `空格` 跳过 |
| 回忆可跳过 | `空格` 随时跳过，画面碎掉而不是硬切 |
| 视角灵敏度 | 0.4×–2.2× |
| 视野 FOV | 50°–80° |
| 静音 | 一键 |
| 无时间压力 | 全作没有任何计时、追逐或失败 |
| 无闪烁 | 没有高频闪光；曝光变化最快也要 1.6 秒完成 |
| 不依赖颜色区分信息 | 交互提示是文字，不是颜色或图标 |

## 八、验证

```bash
npm install
npm run test:nostos        # 单元测试：进度 / 幻象时间轴 / 内容契约 / 交互对焦
npm run typecheck:nostos   # tsc --noEmit
npm run build:nostos       # 类型检查 + 构建
npm run dev:nostos         # 手动游玩 http://127.0.0.1:4175
npm run test:e2e:nostos    # 端到端：从标题走到伊萨卡，顺手拍下逐幕截图
```

e2e 会把每一幕的登岸、线索与回忆写进 `docs/screenshots/`，
它们是美术方向的实拍证据，不是概念图。
