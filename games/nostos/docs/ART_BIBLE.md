# 《归航 · NOSTOS》Art Bible

> 一句话：**把三维几何画成一张被拍下来的湿壁画。**

本作没有一个外部美术文件。所有的石、柱、瓮、船、树、骨、剪影都在运行时用基本体加噪声长出来，
所有纹理都用 Canvas2D 画出来。之所以敢这么做，是因为古希腊壁画与黑绘陶器的语言本来就是
**大块平涂 + 一条边线**——这恰好是程序化几何最擅长的事，也是它最不擅长的"细密写实"的反面。

## 一、颜料

命名沿用颜料而非用途。代码在 `src/content/palette.ts`，场景不得自行硬编码色值。

| 名称 | 值 | 用在哪 |
|---|---|---|
| 骨白 bone | `#e7d9be` | 石灰底、被晒白的骨与石、浪沫 |
| 灰泥 plaster | `#cbb89a` | 未上色的墙、沙、**幻象的纸底** |
| 赭红 terracotta | `#a6402c` | 红绘陶、干涸的颜料、锈 |
| 土黄 ochre | `#c98a3b` | 麻绳、麦秆、被夕阳照亮的石面 |

| 海青 aegean | `#2a4a55` | 中景海水、青铜的冷面 |
| 深海 deepSea | `#14262e` | 远景海水、洞窟深处 |
| 雷云 storm | `#3b3d4a` | 风暴天空、湿透的石头 |
| 金昏 duskGold | `#e0a94e` | 黄昏太阳、火盆、被点亮的雾 |
| 铜绿 verdigris | `#6e8c7a` | 氧化青铜、苔、橄榄叶背面 |

**纪律**：全作只有这十二种颜料。八幕之间的差别不来自换色板，而来自换**天候**——
光的角度与强度、雾的密度与颜色、海的深浅与浪高、后期的分级。同一块石头在忘食岸是暖白，
在独眼岬是湿黑，用的是同一个 `SURFACE.limestone`。

## 二、表面：三阶色带 + 一条边线

`src/engine/materials.ts` 里的 `FrescoMaterial` 是全作唯一的表面着色模型，不是 PBR。

```
明暗 = 0.18（影） / 0.55（中间调） / 1.00（亮面）
```

三档之间用极窄的 `smoothstep` 过渡——过渡窄到几乎是硬边，这是"平涂"的来源。
在此之上叠三件事：

1. **暖色反弹**：影部不是把亮部调暗，而是乘一个天候给定的 `shadowTint`。
   黄昏的影是赭红的，风暴的影是青灰的，亡者之岸的影几乎无色。
   这一项决定了"影子的温度"，也是整部作品看起来不像塑料的主因。
2. **逆光轮廓**：菲涅尔 × 面向太阳的程度，补一道细窄的边线。
   这正是黑绘陶器上人物外缘的那一条勾线。
3. **朝上面提亮**：向上的面被日晒雨冲，比侧面白一点。一根断柱因此立刻有了体积。

**风化**用三平面投影贴一张灰度图（`weatheringTexture()`：斑驳 + 沉积层理 + 麻点 + 随机裂缝）。
程序化几何没有可靠的 UV，所以只能按世界坐标贴——好处是同一块料在任何构件上都连续。

### 太阳阴影

`src/engine/shadow.ts`。一张 2048 的正交深度图，每幕烘一次（地形与构件全是静态的）。

这一项是"是否像剧照"的分水岭：全作大量使用接近地平线的侧光，
**断柱在沙上拖出的那道长影**比任何贴图都更能说明这里有多久没人来过。
掠射角下自阴影很容易起条纹，所以用了斜率平方缩放的法线偏移与偏置，
并在 `N·L` 很低时让阴影自己淡出——那里本来就已经在最暗那一档。

亡者之岸没有方向光，也就关掉阴影：那一幕的设定是"影子不属于任何人"。

## 三、天与海

### 天空（`sky.ts`）
云不是体积云，是**被量化成两三档的平涂色块**，像瓶画上手绘的那一圈云带：
云体 / 亮边两层，硬边，横向流动，云缝里透出逆光。
风暴时云量逼近满、速度快五倍；永昼时几乎无云、天顶被压白；序章点星。

**地平线附近整片交给雾色**。天与海必须在同一处收敛，否则会出现一道接缝——
这是本作反复调过的一处细节。

### 海（`sea.ts`）
- 四道 Gerstner 波叠出方向性，风暴时抬高、拉陡；
- 水色只有深、浅两档，靠菲涅尔硬切换，仍然是壁画读法；
- 太阳方向上一条**碎金光路**：噪声打散成硬边亮点，而不是柔和高光。太阳落到地平线以下整条熄灭；
- 岸线一圈随浪呼吸的白沫，细碎、断续；
- 远处用与天空**完全相同**的雾积分融进地平线。

### 雾（`glsl.ts` 的 `FOG_GLSL`）
沿视线对指数高度分布做解析积分，保证爬坡时雾量连续。
朝太阳的方向雾会被点亮——"咸湿海雾"里那点金色就是这么来的。

**雾在本作里是关卡设计工具，不是氛围装饰。** 它的密度决定了"半封闭"的半径。
禁止用看得见的墙或不可见碰撞盒兜边：走不出去是因为再走就是海。

## 四、镜头（`renderer.ts` / `post.ts` / `controller.ts`）

### 后期链

```
场景 → 高光提取 → 两次一维高斯 → 合成
合成 = 色差 → 光晕 → 曝光 → 胶片曲线 → lift/gamma/gain → 饱和度
       → 幻象双色调 → 暗角 → 颗粒 → 转场 → 遮幅 → sRGB 编码
```

每一项都不是"加滤镜"，而是在补齐真实镜头的物理副作用：

- **halation**：胶片乳剂层背面的反射。高光向外渗，带暖色。
- **颗粒**：银盐颗粒。中间调最重，纯黑与纯白处最轻。
- **暗角**：镜头边缘失光。
- **色差**：镜片对不同波长折射率不同，所以只在画面边缘发生，中心保持锐利。
- **胶片曲线**：肩部压高光、趾部抬黑位，中间保线性。

渲染器的自动色彩空间转换是关掉的：线性值一路走到后期链，
由合成 pass 做**唯一一次** sRGB 编码。这样分级作用在线性光上，和真实调色流程一致。

### 镜头语言

| 场合 | 做法 |
|---|---|
| 默认 | FOV 62°，可在设置里 50–80 调 |
| 走路 | 竖向摆动是横向的两倍频（人走路就是这样），幅度极低；落脚处有 0.6° 的侧倾 |
| 站定 | 呼吸（0.85 Hz）+ 两个不同周期的慢正弦漂移，模拟手持。画面永远不是死的 |
| 凝视 | 看着可触碰之物时 FOV 收窄 2.2°，像人不自觉地眯眼 |
| 登岸 | 移动锁死，镜头以 8–10 秒缓慢横摇过整座岛，FOV 从 +4° 收回基准 |
| 幻象 | 见下 |
| 离岛 | 1.8 秒推向过曝白，硬切下一幕。中间没有航行、没有加载画面里的世界地图 |

`prefers-reduced-motion` 下所有摆动归零，只保留位移。

## 五、回忆幻象的视觉签名

这是本作的表现核心。触碰核心记忆物件后：

1. 环境音退到很远，只剩低频嗡鸣；
2. 遮幅从 2.00 收窄到 **2.39:1**；
3. 世界坍缩成壁画的**石灰底与黑绘墨**两色；
4. 黑绘剪影按旁白的节拍一层层被"画"上去（自下而上的带噪声扫描线，像颜料被刷上去）；
5. 说完最后一句，全部**碎成颗粒**消失。

**关键一条**：幻象里的明暗不来自当前天候的曝光，而是按法线与反照率**重新算一遍**。
否则夜里的幻象会整幅漆黑，正午的幻象会整幅惨白。壁画不管画的是白天还是夜里，
底永远是那块石灰。

玩家在整个过程中**仍然可以转头**。镜头只是被"轻轻推"向该看的方向，不会硬锁——
因为这是他的记忆，不是播给他看的片子。`空格` 随时跳过。

### 剪影母题（`world/silhouette.ts`）

十六个母题，全部用 Canvas2D 一笔一笔画出来：

`galley` 长桨船 · `rower` 划桨的人 · `standing` 站立 · `reaching` 伸手 · `bound` 被缚在桅上 ·
`kneeling` 跪坐 · `eye` 巨大的独眼 · `hand` 巨大的手 · `siren` 鸟身女妖 · `loom` 织机 ·
`flock` 羊群 · `shades` 亡者的行列 · `wreath` 花环 · `threshold` 门槛 · `wave` 卷浪 · `flame` 火

人物由"锥形笔触的四肢 + 收腰的衣身 + 束在脑后的发髻"拼成，是古风时期的画法。

**全作的活人也是黑绘剪影**——四位 NPC 立在世界里就是一片剪影。
这不是省事：叙述者已经无法把他们看成完整的人了。它同时让"没有骨骼动画"
从技术限制变成风格选择——黑绘陶器上的人物本来就是不动的，动的是我们的眼睛。

## 六、界面

游玩时屏幕上永远只有：**一个准星点、一行提示、一条字幕**，
外加左下角一行极淡的 `H 呼唤引路的光`。登岸时多一张幕卡，暂停时多一块面板。

没有血条、小地图、任务栏、收集品清单、指南针、常驻目标标记。

"这里有东西"的提示全部长在**世界里**，不长在屏幕上：
- **光尘**（`world/glint.ts`）：可触碰之物上方一点极淡的光，看向它时稍亮，触碰过之后永远熄灭；
- **引路的光**（`world/guidelight.ts`）：按 `H` 才出现的一串浮空光尘，
  从玩家正前方沿一条二次贝塞尔弧拐向下一处该去的地方，九秒后熄灭。
  控制点放在玩家正前方是刻意的——否则目标在侧后方时，玩家按了键却什么也看不见。

暂停面板里有一列"航程"：走过的幕次显示岛名与记忆物件，当前幕高亮，
未到的一律 `？？？`。终幕则把八段记忆排成一列还给玩家，
再压上全作唯一一次把账算清的那句话。

字体用衬线体——这是一部关于石头上刻着的字的作品。
