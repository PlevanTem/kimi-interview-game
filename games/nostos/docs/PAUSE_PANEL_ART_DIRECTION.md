# 暂停面板 · 航程海图 美术方案

本轮由用户直接要求：把 Esc 面板拆成**基础参数控制 / 操作指引 / 进度**三块，其中八幕进度做成带 3D
设计元素的地图形式，且每座岛的形体要体现这座岛自己的特点——不使用剪影那种扁平形式。

不新增天候、不新增颜料、不新增叙事资产、不引入外部模型或贴图；不改动任何一幕的世界几何。

---

## 一、这块面板现在的三个问题

1. **一根竖列装了全部内容**。`styles.css` 里的 `.panel.pausepanel` 已经写着 `overflow-y: auto`
   与"720p 下必须收紧"的注释——这是布局撑不住的信号。而且顺序是设置在上、航程在下，
   等于把最没有感情的东西放在视觉第一位。
2. **操作指引只有一行 12px 脚注**。七个键挤在一起，其中 `H` 是全作唯一的引导机制，
   世界里专门为它做了 `world/guidelight.ts` 和一行角落提示，面板里却和别的键一样大。
3. **背景压到接近全黑**（`rgba(6, 5, 4, 0.97)`）。面板的标题是「停下来」而不是「暂停」，
   可实现是把画面扔掉。`overlay.ts` 在根节点上挂的 `is-paused` 类，CSS 里没有任何规则用它。

---

## 二、三块的布局

不做标签页。五个设置项加七个按键，藏起来只是多两次点击。1024 px 以上一屏三块同时可见：

```
                       停 下 来            第四幕 · 亡者之岸 · 5 / 8
    ────────────────────────────────────────┬──────────────────
    │  航程                                  │  调校
    │                                        │   五项参数，每项带读数
    │        八 枚 章 的 海 图                │  ────────────────
    │                                        │  舵法
    │  ┌ 悬停卡：岛名 / 记忆物件 / 基调 ┐      │   七个按键，H 独占一行
    ────────────────────────────────────────┴──────────────────
                     返回          从头开始
```

左侧约 62% 给航程，是唯一带情绪的一块；右侧窄栏是工具。1080 px 以下右栏转为横排两列。

## 三、航程：为什么是「章」而不是「地图」

`src/game/scenes/index.ts` 写明八座岛**彼此完全独立**，幕间"没有加载画面里的世界地图"。
一张给出方位与距离的地图会凭空发明一片地中海，和这条设定直接冲突。

所以图上的东西不是地图，是**八枚从世界上挖下来的地块**——奥德修斯自己刻的一套章。
它只表示先后，不表示"在哪儿"。

排法是**两排四枚的蛇形**：第一排从左往右走完序章到第三幕，第二排掉头往回。
起初排的是一条八枚的横排，实测下来那是 7.7 : 1.6 的窄带，塞进接近方形的面板后
每一枚只剩一百像素出头，浮雕与地标全部糊掉。折成两排后占地约 6 : 3.6，和面板的
宽高比对上，每一枚大约放大一倍。

三条它不做的事，比它做的事更重要：

- 不给地理含义。那条 S 只是次序。
- 不揭示没走过的地方（见五）。
- 不引入新的美术。岛形、颜色、光全部来自已有的场景数据。

## 四、形体语言：为什么不是剪影

一枚章在屏幕上大约一百多像素宽。在这个尺度上让人认出"这是独眼岬"，靠的是**形体**——
起伏、层理、投影、侧壁的厚度；八张黑色剪影排开，读出来是八块一样的墨迹。

### 4.1 顶面：真实地形，一比一

每一枚章的顶面由 `terrainHeight()` 逐顶点求值，和玩家脚下踩的是**同一个函数**
（这一轮把它从 `Terrain` 类里抽成了纯函数，网格、行走检测与海图三方共用）。

海岸线不是画出来的圆，是高度过零的地方自然切出来的，所以每一枚章的岸线都不一样。
一旦美术侧另捏一份轮廓，玩家在图上看到的"航程"就不是他走过的那座岛了。

采样用极坐标，30 环 × 72 扇，采到水线之外 1.16 倍半径。

### 4.2 侧壁与底面：它是一块石料，不是一张皮

外缘垂直落下 0.2 图版单位，带一层低频竖向凿痕；底面封平。章有厚度，
低机位掠过时看得见侧面，也不会看穿进去。

### 4.3 两处公开的尺度失真

地貌浮雕从来是失真的，问题只在于失真有没有被写下来：

| 项 | 值 | 为什么 |
| --- | --- | --- |
| 竖向夸张 | **6×** | 见下 |
| 平面半归一化 | `(R/40)^0.55` | 真实半径 26–44 米，等比缩则序章那块沙洲只有独眼岬的 59%，八枚排开会散 |

6 倍是实测出来的，不是拍脑袋。八座岛的中央隆起只有 1.4–5.5 米，半径却有 26–44 米，
**平均坡度只有六度**——这一版先后试过调灯（掠射主光）和加晕渲，都救不回来，
一比一缩到章上就是八块饼。立体地形图用二三十倍夸张是常规，6 倍已经相当克制。

关键是八枚**共用同一个倍数**：亡者之岸缩完仍然最平，独眼岬仍然最高，
岛与岛之间的高低关系没有被改写。逐岛归一化才是说谎。`tests/chart-relief.test.ts`
把这两条都钉住了。

石料立面压到 **0.11** 图版单位，必须小于最平那几枚章自身的起伏——立面一旦盖过浮雕，
八枚一律读成"圆饼 + 一圈厚边"。这是这一轮真实踩过的坑。

地标**不做**竖向夸张，只做等比放大（1.6–2.4 倍）——地形夸张、地标不夸张，
否则一根柱子会拉成一根针。地标落点的 y 乘上同一个 1.8，才不会陷进浮雕里。

### 4.4 地标：每座岛只刻认得出它的那两到四件

全部是有厚度的实体几何，位置照抄各幕 `dress()` 里真实的摆放坐标。
章是记忆，不是缩微模型——玩家想起忘食岸，想起的是果树和那一行只有去程的脚印，
不是岛上一共有多少块卵石。

| 幕 | 岛 | 地形（真实参数） | 章上刻什么 |
| --- | --- | --- | --- |
| 序 | 无名之海 | r26 dome2.1 amp1.05 · 最小最平的一片沙洲 | 散架的木筏、斜插的断桨、几块碎礁 |
| 一 | 忘食岸 | r42 dome2.4 ridge0.5 · 宽而低的沙丘 | 三棵果树（干+冠两件套）、**只有去程**的一行脚印、断柱 |
| 二 | 独眼岬 | r44 dome5.5 amp2.8 **ridge1.8** + 台地 + 凹谷 · 最高最碎 | 三层退进的洞口（真的负形）、巨兽肋骨、碎礁群 |
| 三 | 喀耳刻的柱廊 | r40 **plateau r24** · 半座岛被削平 | 两排列柱（越靠海越残）、楣石、塌下的屋顶一角、地上那幅壁画 |
| 四 | 亡者之岸 | r38 dome1.4 amp1.1 + 坑 · 平、白 | 一列界石（两面磨平，**不刻字**）、没点的柴、祭酒碗与它旁边空着的位置 |
| 五 | 塞壬水道 | r40 **ridge2.8** amp3.4 · 层理最重 | 三具船头朝里的沉船、立着的桅（齐胸一圈磨白）、两侧礁群 |
| 六 | 卡吕普索之岛 | r40 dome4.8 + 台地 | **二十个**树桩、一列雪松、洞口、四道泉、他造的那条船 |
| 七 | 伊萨卡 | r38 dome4.4 + plateau r14 | 全作唯一一座完整的屋（含门槛石）、屋顶那缕烟、橄榄树 |

两条要留意的：

- **树永远是"树干 + 树冠"两件套**（`ART_BIBLE` 第七节的硬规矩）。章上没有人会撞头，
  但形体规矩要一致——一棵冠贴着地的树缩到章上就是一个蘑菇。
- **二十个树桩就是二十个**。玩家在岛上数过。

### 4.5 全图唯一一处刻意偏差

塞壬水道在世界里是被**雾和两侧礁石**收出来的：玩家站在水面上，用视线的封闭感读出"这是一条道"。
从上方看一枚章，雾没有了，那条道就消失了，只剩一块普通的碎礁。所以图上把它真的切开
（`ChartCarve`，半宽 7.5 米、深 5.2 米）。

这处偏差写在 `atlas.ts` 的数据里而不是藏在几何代码中，是为了让它是一个**被记录的决定**。

## 五、三种状态

| 状态 | 章 | 光 | 字 |
| --- | --- | --- | --- |
| 未到 | **一块未刻的石料**：只有侧壁与粗坯顶面，没有地形、没有地标 | 无 | 无 |
| 当前 | 完整刻出，抬起 0.085，按 2.6 秒呼吸 | 自己的天候，亮度脉动 ±12% | 岛名 |
| 已过 | 完整刻出 | 自己的天候，约四成亮度 | 岛名 + 记忆物件 |

`ART_BIBLE` 第六节要求未到的幕不揭示。"一块还没动过凿子的石头"比八个 `？？？` 说得更清楚：
它不是缺了什么，是**还没有发生**。

> 需要一次决定：当前实现（`overlay.ts` 的 `setProgress`）让八幕名称全程可见，与 `ART_BIBLE`
> 冲突。本方案按 ART_BIBLE 走；若改判，两处必须同时改。

## 六、光：每一枚章带着自己的天候

全图只有一盏中性主光和一盏半球光负责读形体。**颜色全部来自各幕自己的天候预设**：

- 主光色 = 该幕的 `sunColor`
- 章底那层贴地的雾 = 该幕的 `horizonColor`
- 章外那圈水 = 该幕的 `seaShallow`

于是八枚排开就是全作的天候节奏——靛蓝 → 蜜金 → 雷暴 → 琥珀 → 无光 → 铅灰 → 永昼 → 转晴，
风暴与黄昏交替，最暗的一幕压在正中间。这条节奏本来只写在 `scenes/index.ts` 的注释里，
现在它是看得见的。

每枚章的点光 `distance` 收到 1.15，邻岛不串色；串了这条节奏就糊成一片。
亡者之岸的太阳强度接近零，给一个 0.45 的下限，否则读不出形体。

顶面着色照抄 `materials.ts` 壁画着色器的那几行：同样的 0.62 / 0.86 陡面阈值、
同样的 heightStart / heightEnd 高地阈值、同样的三色。章上的岛因此和玩家眼里的岛同色相
（只整体提亮 1.28 倍——壁画三色是给带后期分级的场景配的，章上没有那条链子）。

### 六点一、晕渲：形体不靠实时光

缓坡在 Lambert 下照不出形体，这一点做之前不明显，做完一眼就看得见。所以坡向
**直接烘进顶点色**（`geometry.ts` 的 `hillshade()`）：法线按竖向夸张后的地形求，
和主光同向点乘，压进 [0.58, 1.30]。这是地貌图做了一百年的办法。

实时那盏主光仍然留着，但它的活变了——只负责**地标投在地形上的影子**，
那是烘不进去的。半球光则必须给小（0.45）：它只按法线的 y 分量给光，
而浅穹顶的法线几乎处处朝上，开大就等于把八枚章重新照平。

## 七、航线

相邻两枚章之间用**二次贝塞尔**串起来——和世界里按 `H` 唤出的引路的光是同一种曲线。
玩家在岛上跟着走的那道弧，和图上他走过的那条线，是同一句话的两种说法。

走过的段填金（`duskGold`），两端淡出；没走的只是图版上一道空槽。

---

## 八、运动与相机

30° 视场、低角度俯瞰。太高就成了平面图，看不见侧壁与浮雕的投影；太低则后面几枚被挡住。

机位不写死：`frameAll()` 按八枚章的实际包围盒与当前宽高比算出机距，
面板从 21:9 到竖屏都不会切掉两头的章。

注视点固定在图版中心。曾经让它朝当前幕偏 22%，结果是镜头挪了、取景宽度没跟着变，
走到最后一幕时最左边那枚被挤出画面——当前幕本来就靠抬起、点亮自己的天候和呼吸来指认，
不必再动镜头。

鼠标视差 ±0.16 / ±0.09，`reducedMotion` 下全部关闭（视差、呼吸、光脉动、烟）。

全图唯一在动的地标是伊萨卡屋顶那缕烟：终点是活的。

| 项 | 值 |

暂停时才渲染，恢复即停。

## 十、其余两块的改动

**调校**：五项滑杆现在**全都没有读数**，玩家是盲拖——补上 `62°` / `1.15×` / `1.00×`。
布尔的「静音」换成音量滑杆（`engine/audio.ts` 够支撑）。冻帧仍在身后，
拖视野能直接看见画面变化；灵敏度预览不了，指针已经释放。

**舵法**：七个键做成石刻小方块，沿用世界里 `E` 提示那个 `<em>` 的读法。
`H` 独占一行并带半句说明——它是全作唯一的引导机制。

**「停下来」的手感**：冻帧压到约 35% 亮度、去饱和、轻微模糊，但**不清空**；
音景走低通下潜而不是切断——停下来时还应该听得见海。`is-paused` 那个空类正好接这套。
`backdrop-filter` 在低端机上糊全屏 canvas 有开销，退路是暂停瞬间把一帧渲到贴图上模糊一次。

## 十一、本地审阅

```
npm run chart:nostos     # → games/nostos/docs/pause-panel.html（单文件，可直接双击）
```

页面是完整的 Esc 面板：三块同屏，海图可悬停、可点击。左下角那条控制带**不属于面板设计**，
它只是用来把八种进度状态一一过一遍——拖到第 0 幕，除了序章全是未刻的石料；
拖到第 7 幕，八枚全部刻出。评审时请把它当成不存在。

## 十三、这一版还没做好的

预览页能跑、能看，但离能并进游戏还差几件，按值当排：

1. **未刻的石料读成一个洞**。它现在只有半球光，形体太弱，看上去像图版上的黑影
   而不是一块没动过凿子的石头。需要给粗坯顶面做真的凿痕起伏。
2. **整体偏暗**。壁画三色本身就暗，叠上面板的压暗背景之后中间调几乎没有。
   提亮 1.28 倍只是止血，正确的做法是给章一套专用的明度曲线。
3. **航线看不见**。金线现在压在图版上，被前排的章挡掉大半，需要重新找它的高度与走线。
4. **悬停卡与点击**已接好但预览截图里看不到，要动鼠标才出。
