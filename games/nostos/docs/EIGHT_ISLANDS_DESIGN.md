# 归航 · 八岛环境设计 R1

历史设计初稿。用户已在 R2 授权并推进余下六岛；当前细化规格见 `EIGHT_ISLANDS_R2_SPEC.md`，实现与证据对照见 `EIGHT_ISLANDS_R2_IMPLEMENTATION.md`。下面的“两岛样板”边界保留为当时记录，不代表当前进度。

输入版本：`0b89ed0`；run：`run-20260922-eight-islands-r1`。用户 2026-09-22 批准本方案与 Three.js 技术延续。

**交付边界：八岛设计 + 喀耳刻 / 独眼岬两个实机样板。其余六岛尚未实施本轮重构；全量制作等待样板人工审阅。没有发布、合并或手机性能通过记录。**

## 共同规则

人的眼高 1.68m，门洞净宽至少 1.8m，主路净宽 2.4–4m，室内路线不增加楼层或跳跃。巨人尺度只用于独眼岬的家具和洞居，玩家路径仍按人尺度留通道。地形、地板和海图读取同一高度函数，墙体碰撞使用线段胶囊，厚度含 0.28m 人体余量。

建筑按四条因果组织：场地决定朝向与基础；梁、柱、墙、屋面构成传力关系；取水、储藏、遮阴、织作和靠泊解释生活；盐蚀、雨痕、根系和修补解释时间。不做考古复原声明：造型是原创的叙事建筑。

色彩沿用石灰、赭红陶土、氧化铜绿、盐木与深海色，但允许局部颜料改变。单岛一个轮廓主角、一组生活设施、一条远景方向。空间留白不能用随机碎石补满。墙脚压入地基，树根接地，水沟按单向落差走向水口。外露矿物与木材才显著湿润，室内保持干燥。

画面用 **1. 登岸辨认轮廓；2. 行走发生遮挡变化；3. 近看发现使用痕迹** 三层验收。全部目标为第一人称可达机位，不以航拍代替游玩体验。

## 00 无名之海 / 缺口月牙

- **平面**：现有沙洲中轴保持畅通；左侧沿岸形成三段不连续的弧形岩脊，木筏位于弧线缺口内。右侧断船肋朝导星方向倾斜，远景保留空海。
- **剖面**：低潮沟低于沙面 0.15–0.3m；岩脊露出 0.4–1.2m；船肋最高 2.8m。由低到高的三段节奏不封闭玩家视线，不加居民建筑。
- **资产**：3 段侵蚀岩脊、2 组木板沉积、1 段断船肋、潮痕带与浅水沟；复用木筏、断桨、导星。
- **气候**：靛蓝黎明、低饱和冷反光，浪与漂浮碎沫顺同一主风向。岸线湿暗，岩脊顶面干燥；不加金色太阳。
- **目标镜头**：远景以岩脊缺口框空海；中景木筏被一根倾斜船肋短暂遮挡；近景绳结纤维与水磨木端清晰。
- **失败信号**：变成废墟岛、岩脊看似装饰围墙、导星被遮住。

## 01 忘食岸 / 倒伏的花冠

- **平面**：果园主庭 18×14m，西北低矮棚廊组成不完整半月；东侧留约 6m 宽的海口，入口与出口不对称。头盔、果树、水手维持既有叙事锚点。
- **剖面**：两级果园台地各高 0.35m，以 4m 长缓坡连接；矮墙 0.7m，棚檐 2.6m，偏心屋脊 3.4m，果冠 3.5–5m。屋顶弧形来自短跨梁逐段转角，不是悬浮曲面。
- **资产**：3 段转角陶土棚廊、1 组晾果架、2 组陶罐储藏、引水浅渠、石座与低挡土墙；复用果树、水手和头盔。
- **气候**：晴暖海风在棚廊后减弱；疏叶投影，阴处偏海青、日照偏蜂蜜，不用全屏黄色滤镜。
- **目标镜头**：登岸先见偏低屋脊后见树冠；中景果园开口框住坐着的人；近景空头盔和成熟果实形成选择的对照。
- **失败信号**：所有树等距、建筑围成对称神殿、果园像一堵叶墙。

## 02 独眼岬 / 折断的山颚 — 实机样板

- **平面**：保留偏心楔形洞口。羊栏 → 中央下切羊道 → 洞口高台 → 两侧储藏壁龛。洞内家具位于 x=±4–6m，木桩前方中轴保持空白。
- **剖面**：洞内地面 3.2m；净空约 7m。储藏台高 0.6m，器物高 1.25m，壁龛顶约 3.45m（相对洞内地面）；不是给人建的小厨房。侧壁连续支撑，巨大倾斜层理承担屋盖轮廓。
- **资产**：`game.nostos.environment.cyclops_husbandry`（3,720 顶点第二稿，预算 8,000）；延续 `cyclops_cave`；新增羊道边带、排水沉积与局部雨幕。壁龛改造不遮住回忆中的独眼。
- **气候**：斜向雨线、湿冷玄武岩、云与海浪共用风向。洞顶下雨线裁除，洞内反射减弱；风暴不靠高频闪电制造刺激。
- **目标镜头**：`island-layout.ts` 的 arrival / middle / detail。洞前压迫、进洞后两侧生活尺度、近景木桩三者必须同时成立。
- **失败信号**：中央出现封门岩、室内穿雨、羊道像人工铺路、洞内设施仍像独立摆放的箱子。

## 03 喀耳刻 / 被屋顶留住的时间 — 实机样板

- **平面**：西织作廊 x[-16,-7],z[-22,2]；东宴饮廊 x[7,16],z[-10,2]；中央露天壁画通道；小水庭偏东，核心酒杯位于北端。建筑净门洞 3m。
- **剖面**：共享地板 3.4m；柱和厚墙承檐，檐下约 5m、偏心屋脊约 7m（相对地板）。木三角架、拉梁、柱头、墙体与基础连续。屋面在朝海侧缺损，墙脚随真实地形下沉。
- **资产**：`game.nostos.environment.circe_courtyard`（9,456 顶点第二稿，预算 18,000）；厚墙门洞、木屋架、陶土屋面、储藏台、实心座凳、水庭；复用织机、喀耳刻、地面壁画及酒杯。
- **气候**：琥珀日照与冷一点的背光阴影；天井见天，檐下环境反弹光降低。屋面汇水落向偏置水庭，排出口通向平台外侧。
- **目标镜头**：登岸先见高低错开的屋脊；中景左右廊形成不同深度；近景织机背后显出储藏和生活层次。不得以遮住人物换取柱廊构图。
- **失败信号**：两排等长棚屋、承重处有空隙、光照把所有材质染成同一块金色、屋顶挡住回忆。

## 04 亡者之岸 / 没有围墙的边界

- **平面**：六块界石分布于两条错开的低台地边，祭酒坑位于中间浅洼。路线不是直线纪念碑轴线，而是逐次辨认石、影子、空位。
- **剖面**：台地高差仅 0.2–0.5m，所有边缘有可走缓坡；界石 1.6–2.3m。低洼雾沿滩地展开，地平线与灰海融合。
- **资产**：2 片潮蚀台地、6 块差异界石、祭酒沟与坑、整齐未燃柴、桨位。无巨型门、无冥府城、无新增 NPC。
- **气候**：弱方向光、静海、灰白层雾；用前景地表清晰度和远景消失体现深度，不靠黑暗遮掩空场景。
- **目标镜头**：登岸仅两块石清晰；中景亡者从下一层雾显现；近景祭酒碗和空桨孔组成欠缺的动作。
- **失败信号**：变成恐怖墓园、出现大型圣殿、雾让物件无法寻找。

## 05 塞壬水道 / 被声音折弯的船队

- **平面**：两条斜向岩层夹出漏斗，船头沿流向向内；近侧一段倾斜甲板作为可走通路，其他船骸不全部开放。桅杆和绳子仍是终点。
- **剖面**：岩壁 6–12m，甲板抬升 0.6m 且以至少 5m 坡面连接；断船肋以高低三组错开，远景较简、近景显榫接。
- **资产**：3 类倾斜岩板、船骸重组、局部甲板、系泊石、缆绳与风口浪沫；复用八具船骸和核心绳索，不新增大型船只系统。
- **气候**：雾从外海进入风口，迎风面有浪沫、凹湾水面较平，背风处沉积旧绳和碎板。
- **目标镜头**：漏斗端部先见孤立桅杆；中景船肋形成倾斜层次；近景牙痕和受力方向可辨认。
- **失败信号**：沉船随机朝向、甲板无法走、浪沫覆盖所有岸边。

## 06 卡吕普索 / 有尽头的海与无尽的家

- **平面**：保留 R1 左洞居、中四泉、右望海凹岩与造舟清理地。补齐洞口织作到炉床、储藏、取水的短动线；不重排二十个树桩与既有线索。
- **剖面**：洞内按人尺度净高 2.5–4m；入口不做巨大殿门。岩壳厚度可读，滴水沿外缘，不穿入织物区。四泉共享下坡高程并各自入海。
- **资产**：外岩壳次级断面、嵌岩炉床、陶罐储藏凹台、泉水分流口、造舟料架；复用专属人物、织机、挂衣、树桩、雪松与凹岩。
- **气候**：永昼亮而不发白；洞内柔和反弹、草地疏影，面海处有微风，织作处背风。
- **目标镜头**：远景洞居与草地的完整生活；中景泉水将造舟和居住分开；近景未穿衣物与磨损斧柄对照。
- **失败信号**：用花草密度冒充丰盛、泉水上坡、洞内发白无深度。

## 07 伊萨卡 / 围着一棵树修过的家

- **平面**：沿用主宅与橄榄树锚点，西侧增一道偏心院墙把树纳入庭院；东侧灶间、蓄水与储藏为低附屋，门槛仍正对归来路线。只开放门廊及叙事需要的内部视线。
- **剖面**：主宅檐高 3.6–4.2m、错位坡屋脊 5.4m；附屋檐高 2.6m。屋面搭接、排烟口、滴水檐、门楣和台基可解释承重与排水；入口无硬高差。
- **资产**：主屋坡顶、低附屋、雨水槽及蓄水口、修补院墙、灶口与烟、储藏器具；保留活树、织布、门边骨骸与门槛。
- **气候**：雨后放晴，屋檐下较干、院地暗处未干，炊烟随低风偏转；不做胜利式金色光柱。
- **目标镜头**：远景先看到烟再看到屋；中景活树遮住一角屋顶；近景完整门槛与反复修补的墙面承接二十年。
- **失败信号**：宫殿化、废墟化、新增欢迎 NPC、结局镜头被新屋顶挡住。

## 运行与评审

- 本机开发：`npm run dev:nostos -- --port 4188`。
- 样板：`/?preview=circe&quality=high`、`/?preview=cyclops&quality=high`；低档把 quality 改为 low。preview 仅在本机启用，正常存档隔离。
- 证据：当前 run 的 before / after，使用同一 `capture.mjs` 和相同相机；before 来源线上基线，after 来源本地开发版。定时云和风不会逐像素同步，构图和模型可比较。
- 样板接受标准：轮廓比基线有辨识度、室内外可理解、原叙事焦点无遮挡、全部交互可达。人工审阅没有完成时不写 Visual Lock。
- 低档：DPR ≤1，阴影 512²，关闭光晕模糊三 pass；中档 1024²、高档 2048²。动态分辨率有迟滞；不会通过降低 NPC 细节或移除故事物件提速。
- iPhone 13 Safari / Pixel 6 Chrome 各 15 分钟实测仍必需。桌面触摸模拟验证操作契约，不是手机性能证据；实测记录中位 FPS、P95 帧耗时、低帧持续时间和切岛停顿，禁止把加载排除后偷偷提高结论。
