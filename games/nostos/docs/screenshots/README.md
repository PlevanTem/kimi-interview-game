# 逐幕实拍

这里的每一张都是 `npm run test:e2e:nostos` 在真实运行的游戏里截下来的，
不是概念图，也不是手工挑帧。命名规则：

```
<幕号>-<幕 id>-a-登岸.jpg   登岸横摇镜头结束的那一刻，左下角是幕卡
<幕号>-<幕 id>-b-线索.jpg   站在这一幕第一处环境线索前，准星与提示条可见
<幕号>-<幕 id>-c-回忆.jpg   回忆幻象进行到第 12 秒，黑绘剪影已经浮起来
00-title.jpg                 标题
99-终幕.jpg                  伊萨卡之后的字卡
```

CI 环境没有 GPU，跑的是 SwiftShader 软件渲染，所以帧率很低、抗锯齿较弱；
颜色、构图、光影与遮幅与真实 GPU 上一致。图片存成 JPEG（质量 82）——
这些画面本身带胶片颗粒，是连续调，用 PNG 存会让证据目录涨到近 30 MB。

重新生成：

```bash
npm run build:nostos
npm run test:e2e:nostos
```

所有随机都由固定种子驱动，同一个提交跑出来的画面是可复现的。
