# 《归航 · NOSTOS》分幕规格书

八幕，彼此**完全独立**的八座小岛：各自的地形、天候、音景与几何，
上一幕的东西一件也不会出现在下一幕里。幕与幕之间用一次白光过曝硬切，
中间没有航行、没有过场、没有加载画面里的世界地图。

天候的节奏是刻意排的：**靛蓝 → 蜜金 → 雷暴 → 琥珀 → 无光 → 铅灰 → 永昼 → 转晴**。
风暴与黄昏交替，最暗的一幕（亡者之岸）压在正中间。

每一幕的结构是同一个：

> 登岸（固定横摇镜头）→ 漫游 → 沿途触碰 3–5 处**环境线索** →
> 触碰**核心记忆物件** → 一段 35–85 秒的**回忆幻象** → 走向船 → 硬切

实拍画面见 `docs/screenshots/`（由 e2e 自动产出，不是概念图）。

## 序章 · 无名之海 `prologue`

**情绪基调**：失重、无名。世界只剩下水面、一点星光，和一双还记得怎么打绳结的手。

**美术**：黎明前的靛蓝。一片刚够站人的灰色沙洲，浪很大但没有声音的重量。
天上有星（全作唯一一幕），太阳还在地平线以下，所以海面上**没有金光**——只有冷的反光。
沙洲上散着一张已经散架的木筏、几根船肋、一支断桨。没有遗迹，没有神殿，没有故事。

**镜头**：登岸横摇 0.5 弧度 / 7 秒，从空海摇到那张木筏。这一幕的任务只有一件：
教会玩家"走过去、看着它、按一下"。

**环境线索清单**

| 位置 | 提示 | 说的是什么 |
|---|---|---|
| 木筏 | 看绳结 | 手还记得怎么打，人不记得是哪一天打的 |
| 船板 | 读船板 | 有人刻过一个名字，海舔掉了一半 |
| 水边 | 试水温 | 这个季节的海不该是温的 |
| 沙洲高处 | 找那颗星 | 只要它在左手边，就是在往东走 |

**触发式回忆事件** — 核心物件：**断桨**（`prologue.oar`）
> 桨柄上有一圈磨光的地方，正好是一只手的宽度。

幻象 36 秒。三条长桨船依次从雾里被"画"出来，最大的一条在正前方，另外两条在两侧退开；
接着两个划桨的人浮现在近景；最后一道卷浪把画面压住，曝光降到 0.86。

> 十二条船。
> 我数过很多次，每次都是十二条。
> 风从后面来，帆是满的，人在笑。
> 有人问我们要走多久。
> 我说，不久。
> 我说这话的时候，是真的这么以为。

**这一幕存在的理由**：把"十二条船"这个数字立起来。后面七幕每一次沉船，都在减这个数。

## 第一幕 · 忘食岸 `lotus`

**情绪基调**：甜蜜的麻痹。风是暖的，果子是甜的，而所有走进岛里的脚印都没有走回来。

**美术**：蜜金黄昏，风停了。低缓的沙丘，一段登岸口的断柱与矮墙，
再往里是一小片低矮的果树，光被叶子切成一条条。太阳很低，
每一块石头都在沙上拖出很长的影子——这一幕的长影是**时间过去了多久**的度量衡。

**镜头**：横摇 0.6 / 8 秒。走到岛心才看得见那排断柱：地形是缓缓抬起的，
景物一件件从丘背后冒出来，而不是一眼看完。

**环境线索清单**

| 位置 | 提示 | 说的是什么 |
|---|---|---|
| 倒下的酒瓮 | 看酒瓮 | 口朝下，底下的沙是干的——它倒在这里已经很久 |
| 半埋的桨 | 看半埋的桨 | 没有人来把它拔出来 |
| 沙上的脚印 | 看脚印 | 只有去的那一行 |
| 冷掉的火堆 | 拨开灰 | 灰是白的，烧得很彻底，烧完之后没人再添 |
| 果树 | 闻果子 | 低，伸手就够得到；香得让人不想再想别的 |

**NPC**：**留下的人**（跪坐的剪影，坐在一块矮石旁）
> 你来了。／……我认得你，可我想不起在哪儿见的。／这里很好。风是暖的，果子是甜的。／
> 我以前好像很急着去什么地方。／**你要是想起来那是哪儿，别告诉我。**

**触发式回忆事件** — 核心物件：**被丢下的头盔**（`lotus.helmet`）
> 头盔翻在地上，里面积了一层沙。带子是解开的，不是被打掉的。

幻象 52 秒。三个站立的人依次浮现在树下；一顶花环在他们上方成形；
镜头随后被带向远处的船；最后一片"被缚在桅上"的剪影出现在近景，曝光提到 1.18。

> 我派三个人上岸打听，这是规矩。／他们没有回来。／
> 我去找，他们坐在树下吃东西，看见我，笑了。／他们不肯走。／
> **不是打不过我——是他们不想走。**／我把他们捆在桨座下面。／
> 一路上他们哭着求我放开。／**我没有回头。我怕我一回头，也不想走了。**

## 第二幕 · 独眼岬 `cyclops`

**情绪基调**：幽闭与代价。赢了之后还要再赢一次的那种人，最后输给的是自己的名字。

**美术**：雷暴，强逆光。玄武岩的层理被雨浇成一道道黑亮的横纹，海在下面砸礁。
云量 0.92、流速是别幕的五倍，光从云缝里劈下来。地形做了两处人工整形：
洞口所在的**高台**，和洞前下陷的**谷地**——玩家因此是"往下走进去、再往上走出来"。

**镜头**：横摇 **−0.7** / 8 秒（全作唯一一个反向横摇，从海摇向岬角）。
整座岛的构图只有一件事：把玩家推向那个洞口。

**环境线索清单**

| 位置 | 提示 | 说的是什么 |
|---|---|---|
| 石垒的羊栏 | 看羊栏 | 每一块石头都太大了，不是给人搬的 |
| 巨兽的肋骨 | 看肋骨 | 一根比我高，断口是新的 |
| 压扁的青铜盾 | 认那面盾 | 被压成一张饼，中央的纹章还在，**是我们的** |
| 石缝里的羊毛 | 看石缝 | 一撮一撮排得很整齐，像有什么贴着石壁被慢慢拖出去过 |
| 洞口的焦木 | 看焦木 | 有一根削得很尖 |

**触发式回忆事件** — 核心物件：**削尖的橄榄木桩**（`cyclops.stake`）
> 橄榄木。尖端烧硬过。我记得这个重量。

幻象 84 秒，全作最长。门槛 → 一个同伴 → 一只巨大的独眼在头顶张开（镜头被抬起 0.12 弧度）→
火（曝光冲到 1.35）→ 一只巨手 → 羊群 → 船 → 一个站在船尾的人影 →
镜头推近、曝光再冲一次 → **独眼以影色重新出现，曝光压到 0.75** → 一道卷浪。

> 洞很深，门口那块石头我们十二个人推不动。／他先吃了两个，才问我们是谁。／
> **我说，我叫「没有人」。**／我们把木桩烧红，六个人抬着，捅进去。／
> 他喊了一夜。外面的人问他怎么了。／他喊：没有人在害我。／**于是没有人来。**／
> 天亮我们贴在羊肚子下面爬出去。／船离岸了。**我本来已经赢了。**／
> 我站在船尾，冲着岸上喊出了我的名字。／我要他知道是谁弄瞎了他。／
> ……他知道了。他把这个名字，告诉了他的父亲。／**海从那一天起，认识我了。**

**这一幕存在的理由**：全作最恐怖的一段，恐怖的不是怪物，是主角自己那句话。
后面每一次风暴都是这句话的回声。

## 第三幕 · 喀耳刻的柱廊 `circe`

**情绪基调**：温柔的时间流失。没有人被囚禁，所有人只是坐下来吃饭，然后一年过去了。

**美术**：琥珀色的室内光，一丝风也没有（云速 0.004，全作最慢）。
一块抬高 3.4 米的石台上立着两排七根多利安列柱，光被切成一根根竖条，
落在剥了大半的地面壁画上。**废墟是有方向的**：靠海一侧的柱子断得最厉害，
越往里越完整——海从那个方向来了很多年。

**镜头**：横摇 0.45 / 8 秒。所有可读的东西都摆在柱距之间，
玩家每走过一根柱子就换一幅画。

**环境线索清单**

| 位置 | 提示 | 说的是什么 |
|---|---|---|
| 爬进来的藤 | 看藤 | 从门外长进来，爬过柱子，又爬回门外——**它走完了一个来回，我们没有** |
| 地面壁画 | 看地上的画 | 一排人弯着腰，越往后越不像人 |
| 一排酒杯 | 看那排杯子 | 摆得很齐，每一只都空了，杯底一圈干掉的红痕 |
| 织机 | 看织机 | 经线还绷着，织了很长一段，看不出要织成什么 |
| 屋顶缺口 | 看塌下来的地方 | 少了几块瓦，底下的地面凹进去一小块 |

**NPC**：**喀耳刻**（站立的剪影，在织机旁）
> 你又来看这架织机。／你已经看了很多次了。／**一年。你们在这里待了一年。**／
> 没有一个人问过我"我们该走了吗"。／**包括你。**／
> ……走吧。路我告诉过你了，你只是一直没有听。

**触发式回忆事件** — 核心物件：**没喝完的酒杯**（`circe.cup`）
> 杯子还是满的。端起来的人没有把它喝完，就再也没回来端第二次。

幻象 66 秒。跪着走路的人 → 站起来的人 → 花环 → **织机**（镜头被带向左侧 0.26 弧度）→
提醒他的人（镜头转回右侧）→ 曝光压到 0.82 的那一年 →
一片"伸手"的剪影**只用 0.5 秒就出现、随即立刻崩解**（那是从屋顶摔下去的人）→ 船。

> 我的人先进去，回来的时候趴着走。／我拔了剑，她笑了，说：把剑收起来，坐下吃饭。／
> **于是我们坐下吃饭。**／第二天也是。／第三天也是。／春天来了又过去，我没有注意。／
> 是我的人来提醒我的。他说，我们是不是该走了。／我算了算——一年。／
> 走的那天早上，最年轻的那个从屋顶上摔了下来。／**我们急着上船，没有埋他。**

## 第四幕 · 亡者之岸 `nekyia`

**情绪基调**：肃穆、赎罪。这里没有惩罚，只有一件一件没有做完的事，安静地等在原地。

**美术**：**没有太阳，没有方向光，没有影子**（阴影在这一幕被关掉）。
饱和度拉到 0.12——不是黑白，是被漂过的灰白，像一张放久了的湿壁画。
雾密度是全作最高，能见度只剩十几米。海面几乎不动（浪高 0.06）。
灰白的沙上什么也没有，除了六块两面磨平、上面没有字的界石。

**镜头**：横摇 0.3 / 9 秒——全作最小的横摇，因为这一幕不该有"景色"。

**环境线索清单**

| 位置 | 提示 | 说的是什么 |
|---|---|---|
| 灰白的沙 | 回头看 | **我自己的脚印也没有** |
| 界石 | 看界石 | 两面都磨平了。这里不需要写谁在里面 |
| 没点的柴 | 看那堆柴 | 摆得很规矩，柴是新的 |
| 插过桨的洞 | 看沙地上的洞 | 坑还在，桨不见了 |
| 挖好的坑 | 看那个坑 | 边沿很利落，底下是干的——**该倒进去的东西，谁都没有倒** |

**NPC**：**一个年轻的影子**（站立的剪影）——他是第三幕里从屋顶摔下去的那个人
> 你还是来了。／我从屋顶上摔下来的时候，你们已经在装船了。／
> 我不怪你。急着走的人听不见身后的声音。／……可是你们连一捧土都没有给我。／
> **把我的桨插在坟上。就一支桨，插在土里。**／
> 这样后来的人经过，会知道这里躺过一个划船的人。

**触发式回忆事件** — 核心物件：**空的祭酒碗**（`nekyia.bowl`）
> 碗是空的，里面结着一层白。倒进去的东西，被喝掉了。

幻象 78 秒。跪着倒祭酒的人 → **亡者的行列**从四面围上来 → 一个站着的身影 →
接着是全作最狠的一段设计：**同一片"伸手"的剪影出现三次，一次比一次淡、一次比一次快地碎掉**
（1.4 秒浮现 → 0.4 秒浮现、立刻碎 → 0.4 秒浮现、更快碎）。

> 我挖了坑，倒进蜜、奶、酒和水。／影子从四面围上来，像退潮时露出的石头。／
> 我要找的人还没来，我得先赶开别的。／然后我看见了我母亲。／
> 我离家的时候她还活着。／**她说，是等你等死的。**／我伸手去抱她。／
> 第一次，手穿过去了。／第二次，手穿过去了。／**第三次，我停下了。**／
> 她说：记住你现在看见的，回去讲给活着的人听。／
> **这是她留给我的最后一件事——一个任务。**

## 第五幕 · 塞壬水道 `sirens`

**情绪基调**：诱惑与自缚。他不是被骗的那一个，他是提前知道自己会求饶、于是先堵住别人耳朵的那一个。

**美术**：铅灰海雾，能见度第二低。玄武岩与暗礁把水道两侧收得很紧。
礁上横七竖八全是船——**船头都朝着同一个方向，朝里**。
玩家沿着这条由沉船排成的甬道往里走，走到最后是一截立着的桅杆。
这一幕不给任何"美"的奖励：没有黄昏，没有金光，只有湿冷的灰和白骨。

**镜头**：横摇 −0.5 / 8 秒。八具沉船骨架构成一条强透视的引导线。

**环境线索清单**

| 位置 | 提示 | 说的是什么 |
|---|---|---|
| 满礁的沉船 | 看船头的方向 | 船头都朝着同一个方向——朝里 |
| 别人的记航板 | 读记航板 | 刻到一半停了，最后一个符号没刻完 |
| 一坨蜡 | 捡起蜡 | 捏过的形状还在，正好是塞进耳朵的大小 |
| 白骨 | 看那些骨头 | 排得很整齐，**像坐着听什么** |
| 立着的桅杆 | 摸那圈磨痕 | 齐胸高度一圈磨白的痕，绳勒出来的，勒了很久 |

**触发式回忆事件** — 核心物件：**带牙印的绳**（`sirens.rope`）
> 绳子上有牙印。**是从里面咬的。**

幻象 82 秒。被缚在桅上的人 → 两个划桨的人 → 左、右、正上方**三只鸟身女妖**依次浮现
（镜头被带向左 0.3、向右 0.34、再抬头 0.14）→ 曝光冲到 1.16 的挣扎 →
划桨的人以影色重新出现 → 曝光压到 0.8 → 一道卷浪。

> 我让他们把蜡塞进耳朵，把我绑在桅杆上。／我说：不管我怎么喊，都不许解开。／
> **我想听。我一直都想听。**／歌声起来的时候，我听见的不是歌。／
> 是有人在念我做过的每一件事，一件不落，全都念对了。／
> 她们说：留下来，我们把你没弄明白的都讲给你听。／我用尽全身力气挣绳子。／
> 我求他们放开我。我骂他们。我哭。／**他们听不见。他们只是划。**／
> ……我早就知道我会求他们。／**所以我才让他们塞住耳朵。**／
> 这是我这辈子做过最聪明的一件事，也是最丢人的一件。

## 第六幕 · 卡吕普索之岛 `calypso`

**情绪基调**：永生的代价。这里什么都好，好到没有尽头——而他要的恰恰是一个有尽头的人生。

**美术**：**永昼**。太阳挂在 0.62 弧度的高处不动，曝光 1.22、光晕 0.62，
一切都被曝到发白。十棵雪松在白光里是一列列黑竖线。
岛上唯一的"事件"是二十个齐根伐掉的树桩，和海边一处被坐出来的岩石凹陷。
这一幕的美是**过量的**——太亮、太安全、太完整，完整到让人喘不过气。

**镜头**：横摇 0.55 / 9 秒。九秒是全作第二长，因为这一幕需要"待久了"的感觉。

**环境线索清单**

| 位置 | 提示 | 说的是什么 |
|---|---|---|
| 岩石凹陷 | 坐下来看海 | 坐出这么深，要很多年 |
| 四道泉 | 看四道泉 | 从一处流出，分向四边，最后都进了海 |
| 二十个树桩 | 数树桩 | 数目正好够造一条船 |
| 洞口的织机 | 看织了一半的布 | 她织的时候一直在唱歌。我听不懂词 |
| 不朽的衣服 | 看那件衣服 | 织好了，挂着，**没穿过**。布是不会烂的那种 |

**NPC**：**卡吕普索**（站立的剪影，在洞口的高台上）
> 船造好了。／我给了你斧子、钉子、布，还有风。／你要走的东西我全都给了。／
> **我只问过你一次：留下来，我可以让你不死。**／你想都没想。／
> ……她会老。她会死。你也会。／你选了这个。／去吧。别回头看这座岛，它不会一直在这儿。

**触发式回忆事件** — 核心物件：**伐木的斧**（`calypso.axe`）
> 斧刃卷了，木柄被手心磨得发亮。一个人砍二十棵树，要砍多少天。

幻象 66 秒。一个站着的人 → 一道极淡的卷浪（海）→ 一道影色的门槛（家）→
一顶花环，曝光冲到 1.28（不死的许诺）→ 一列亡者的行列（会死的那一边）→
镜头推到最近、曝光压到 0.88 的那一句"我还是要回去" → 船。

> 第七年。／白天我坐在这块石头上看海。／晚上我回洞里，因为除了洞里没有别的地方可去。／
> 她说：留下来。你不会老，不会病，不会死。／她说：那个女人会老，会死，会忘了你。／
> **她说的每一句都是真的。**／我说：我知道。／**我说：我还是要回去。**／
> 她没有再问第二次。／第二天她给了我斧子。

## 终章 · 伊萨卡 `ithaca`

**情绪基调**：抵达后的空茫。想了二十年的那一刻真的到了，安静得几乎像一场误会。

**美术**：雾正在散。这是全作唯一一幕**没有废墟**的岛：
房子是完整的，四面墙、门楣、门廊两根柱、屋顶都在；屋顶上有烟。橄榄树还在长。
前面几幕堆起来的断柱与沉船在这里**全部缺席**——缺席本身就是结局。
从岸边到院子有一条用石头标出来的路，这是全作唯一一条"被人走出来的路"。

**镜头**：横摇 0.4 / **10 秒**，全作最长的登岸镜头。因为这一次值得多看一会儿。

**环境线索清单**

| 位置 | 提示 | 说的是什么 |
|---|---|---|
| 屋顶 | 看屋顶 | 有烟。有人在里面生火做饭 |
| 橄榄树 | 摸树干 | 很多年前我用它的根做过一张床的床脚。**树还在长。床应该也还在。** |
| 门边的骨头 | 看门边的骨头 | 很小的一副，趴着的地方正对着路口 |
| 织了又拆的布 | 看那块布 | 边上拆过很多次，拆的针脚和织的针脚一样细 |
| 门槛石 | （核心记忆） | 中间凹下去一道 |

**没有 NPC。** 没有号角，没有跑过来的人。这一幕的安静是设计出来的。

**触发式回忆事件** — 核心物件：**门槛**（`ithaca.threshold`）
> 我在这块石头前面站住了。

幻象 58 秒。门槛 → 火 → 一条影色的、半透明的长桨船（十年的仗）→
一列影色的亡者行列（死在路上的人，镜头被带向右侧 0.26）→ 镜头推近 →
花环，曝光冲到 1.22 → 镜头推到最近的 −16° FOV。

> 我以为回来的那一刻会有声音。／号角，或者哭，或者跑过来的脚步。／**没有。**／
> 只有烟，和风吹过橄榄叶。／十年打仗，十年回家。／我记得每一个死在路上的人的名字。／
> 现在我要走进去，说出我自己的。／**我叫奥德修斯。**／**我回来了。**

幻象结束，画面转黑，压上：

> 《归航 · NOSTOS》
> 献给所有还在路上的人

## 全作的一条暗线

主角**从不说自己的名字**——从序章"有人在船板上刻过一个名字，海把它舔掉了一半"开始，
到第二幕"我叫「没有人」"、"我冲着岸上喊出了我的名字"（但玩家仍然听不到那个名字），
一路到终章的最后第二句。整部作品都在等那一下。

这也是为什么八幕的顺序不能改。
