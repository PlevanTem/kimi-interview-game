# 《光线之上》玩法与体验规格 v1

状态：Gate 1 与 Godot Tech Fit 已锁定；正在生产等待用户直测的完整 Demo  
主动作：**驭线**  
目标平台：桌面浏览器  
Gate 2 单局：3–5 分钟  
完整产品目标：90–150 分钟，Gate 2 后复核

## 1. 设计判断

本作不是“边跑边画平台”，而是“与一个有自我节拍的人共同演奏一条会承重的线”。玩家的表达空间来自同一个动作的三个连续维度：线形决定空间、张力决定运动、释放时机决定节拍。

采用上田文人的“设计减法”视角作为审查框架：每个系统都必须同时增强**旅者关系、身体可读性或张弛节奏**，否则删除。这里借用的是设计视角，不是声称复刻其作品。

## 2. 玩家目标与体验承诺

### 显性目标

在城市每次呼吸闭合前，驭使一条动态光线帮助阿迦跨越断层，到达晨光终台。

### 隐性目标

从“替他铺路”转向“读懂他的步伐并与他同步”，最终理解前进也包括主动停下。

### 玩家应说出的句子

- “我不是画完再看他走，我是在他跑的时候接住他。”
- “我知道什么时候该绷紧，也知道什么时候该松手。”
- “他会先试探我，不是一个等命令的棋子。”

若大多数测试者只说“画线让小人过去”，核心承诺未成立。

## 3. 单一主动作：驭线

“驭线”是一个持续动作，不拆成四个并列技能：

1. **起线**：按住主指针，从当前合法起点引出光线。
2. **借锚**：轨迹进入锚点容差区时，线自动绕过锚点；玩家通过路径选择决定是否借锚。
3. **调势**：继续移动指针改变弧度和有效长度；系统实时计算松弛、承重、紧绷、过载。
4. **放势**：在阿迦脚步提示窗口内松开同一次指针输入，把当前线势释放为支撑、摆荡或弹射。
5. **收线**：跨越完成或取消后，余光沿线回收；玩家进入下一次预读。

辅助操作不构成核心动词：`Esc` 暂停，`R` 重开当前单局，右键/次按键取消未生效线段。长按不便的玩家可用“点击开始、再次点击释放”的等价模式。不得在 Gate 2 增加跳跃键、角色移动键、独立放光键、技能轮盘或独立锚定键。

## 4. 25–45 秒核心循环

| 阶段 | 时长 | 玩家任务 | 阿迦行为 | 系统反馈 |
|---|---:|---|---|---|
| 预读 | 4–6 秒 | 看断层、锚点与重心 | 降速、看向落点、脚尖试探 | 世界吸气；安全起点亮起 |
| 起线/借锚 | 5–10 秒 | 织出可承重曲线 | 继续接近起跳点 | 线形与张力连续变化 |
| 调势同行 | 8–15 秒 | 边移动线端边维持可用势能 | 上线奔跑、下坠或摆荡 | 足音、线鸣、镜头呼吸同步 |
| 放势 | 2–4 秒 | 在身体前兆后释放 | 起跳、换手或落地 | 脉冲沿线传播并改变运动 |
| 停息 | 6–10 秒 | 无强制输入，观察余波 | 检查伤痕、回望或短坐 | 世界呼气；叙事痕迹显现 |

四至六次循环组成一局。每三次循环后插入 15–25 秒可自行提前离开的静息平台；不以文字框打断控制。

## 5. Gate 2 路线

灰盒只制作一条连续路线：

1. **平跨**：一处宽容断层，教会起线、承重与第一次放势。
2. **低谷**：线会明显下坠，玩家首次通过调势避免擦底。
3. **摆荡**：必须借一个锚点，让阿迦抓线换向。
4. **双拍**：连续两次身体提示，验证玩家能否保持而不是只点一次。
5. **弹射**：以紧绷线势越过高差；过紧会撞上上沿，过松会差一步。
6. **静息终台**：阿迦主动停下，玩家不输入才完成最后节拍。

可复用基础几何、胶囊角色和程序化曲线。每段只引入一个新变量，不能靠正式美术遮盖规则不清。

## 6. 首次 30 秒教程

| 时间 | 事件 | 教学方式 | 通过判定 |
|---|---|---|---|
| 0–8 秒 | 世界减速，起点与落点间出现未完成余辉 | 光点跟随指针；按住后线条立即承重 | 玩家开始连续指向 |
| 8–15 秒 | 阿迦踏上线并用脚尖轻点两下 | 第二下形成全场唯一高亮节拍环 | 玩家看到身体提示 |
| 15–22 秒 | 节拍窗变宽，等待玩家放势 | 松开当前线；过早不会死亡，只产生弱脉冲 | 完成第一段短跳 |
| 22–30 秒 | 抵达安全平台，镜头与环境同时呼气 | 无文字奖励；余光揭出一件旧物 | 玩家停留或主动起下一线 |

如果玩家 8 秒内没有起线，余辉缓慢演示一次手势；若 15 秒仍未行动，阿迦回头看玩家并再次试探。不得直接代画完整路线。

## 7. 阿迦的可读身体语言

阿迦不是光线上的载荷，而是另一个行动者。

| 意图 | 身体前兆 | 声音前兆 | 玩家可推断 |
|---|---|---|---|
| 准备承重 | 脚尖轻点两次、肩部前倾 | 两下干燥鞋底声 | 第二拍后可释放支撑 |
| 准备跃迁 | 重心压低、目光锁定上方落点 | 吸气缩短 | 需要较紧线势 |
| 准备摆荡 | 手臂先伸向锚点、躯干侧转 | 金属扣轻响 | 保持松弛，不要提前弹射 |
| 线势危险 | 一手下压线、另一手张开 | 线鸣出现颤音 | 需要调势而非立即放势 |
| 拒绝前进 | 双脚站稳并看向记忆痕迹 | 足音停止 | 当前正确动作是停息 |

同一意图必须同时提供姿态、运动和声音三种线索，不能只靠颜色或图标。

## 8. 状态机

### 8.1 状态

- `BOOT`：载入最小资源与可重放配置。
- `TITLE`：开始、控制说明、可访问设置。
- `TUTORIAL_TRACE`：首次起线教学。
- `TUTORIAL_PULSE`：首次身体提示与放势教学。
- `OBSERVE`：安全点预读；允许起线。
- `WEAVE`：连续编辑当前光线；实时计算线势。
- `TRAVERSE`：阿迦与线交互；玩家仍可调势。
- `PULSE_WINDOW`：`TRAVERSE` 的节拍窗口标记，不抢占运动状态。
- `REST`：安全节点；叙事和呼吸恢复。
- `REWIND`：回放失败前余波并恢复最近合法快照。
- `PAUSED`：冻结模拟、输入判定和音频相位。
- `RUN_SUCCESS`：静息终台完成；可重开或返回标题。
- `RUN_FAILURE`：当前节点连续三次失稳，光核熄灭；可立即重开同种子。
- `RECOVERY`：检测到非法组合后回到最近快照或安全节点。

### 8.2 主要事件与守卫

| 事件 | 来源状态 | 守卫 | 目标状态 |
|---|---|---|---|
| `START_RUN` | `TITLE` | 配置与种子有效 | `TUTORIAL_TRACE` 或 `OBSERVE` |
| `POINTER_BEGIN` | `OBSERVE` | 起点合法且未暂停 | `WEAVE` |
| `POINTER_MOVE` | `WEAVE`/`TRAVERSE` | 指针样本合法 | 原状态并更新线势 |
| `LINE_ACCEPTED` | `WEAVE` | 至少一条可承重区间 | `TRAVERSE` |
| `END_HARNESS` | `WEAVE`/`TRAVERSE` | 当前曲线可提交 | 锁线并计算早/中/晚脉冲，进入 `TRAVERSE` |
| `SAFE_LAND` | `TRAVERSE` | 角色进入安全体积且速度可接受 | `REST` |
| `REST_DONE` | `REST` | 玩家起线或最长停息时间到 | `OBSERVE` |
| `INSTABILITY` | `WEAVE`/`TRAVERSE` | 跌落、过载断线或碰撞 | `REWIND` 或 `RUN_FAILURE` |
| `REWIND_DONE` | `REWIND` | 快照通过合法性校验 | `OBSERVE` |
| `PAUSE` | 任意可游玩状态 | 非过场锁 | `PAUSED` |
| `RESUME` | `PAUSED` | 原状态快照合法 | 返回原状态 |
| `RESTART` | 任意非载入状态 | 无 | `OBSERVE` 或首次教程 |
| `FINAL_STILLNESS` | `REST` | 最终台连续 4 秒无驭线输入 | `RUN_SUCCESS` |

### 8.3 失败与恢复

- 每次失稳先进入 `REWIND`，回看不超过 1.2 秒，再恢复到最近 6–10 秒内的合法快照。
- 快照至少包含：随机种子、固定步编号、阿迦姿态与速度、线控制点与张力、锚点占用、脉冲相位、失败计数、当前节点。
- 一个节点连续三次失稳进入 `RUN_FAILURE`；这是完整失败状态，不删除回溯机制。
- 连续两次失稳后，只允许降低世界脉冲速度 10% 并扩大锚点视觉外圈；不得改变阿迦本体运动学、自动吸附路线或偷偷延长成功窗口。
- `REWIND` 中不接受新的驭线输入；暂停后恢复不得重复消费之前的 `PULSE`。

### 8.4 非法状态恢复

以下组合视为非法：无有效线却处于承重、暂停时固定步推进、快照步号倒退、角色位于安全体积外却标记 `REST`、同一输入序号被消费两次。

处理顺序：记录诊断事件 → 停止判定和奖励 → 校验最近合法快照 → 成功则进入 `RECOVERY` 后恢复 `OBSERVE` → 无快照则进入 `RUN_FAILURE`。不得静默修正并继续计分。

## 9. 线势规则

Gate 2 不追求真实绳索物理，而追求确定、可读、可调：

- 曲线由有限控制点和锚点生成；输入先量化，再进入固定步模拟。
- `slackRatio` 表示有效线长相对端点与锚点路径的余量。
- 线势分四档：`LOOSE`、`SUPPORTED`、`TAUT`、`OVERLOADED`。
- 状态阈值必须有滞回，避免在边界闪烁；具体数值由 spike 决定。
- 脉冲不是独立攻击，而是沿当前曲线传播的势能释放。
- 结果由线势、阿迦相位与释放时机共同决定；不得由隐藏随机数决定。

## 10. 信息与反馈

### 世界内反馈

- 线宽：负载越大越窄，但保持最小可见宽度。
- 曲线形变：松弛下坠、承重稳定、紧绷出现纵向拉纹、过载出现局部白化和颤动。
- 脉冲：从玩家控制端沿弧长传播，抵达阿迦时触发动作，不做瞬时全线闪光。
- 锚点：仅在可借锚范围内产生几何开合，不用常驻 UI 标签。
- 世界呼吸：预读时吸气，放势时短暂停顿，落地后呼气。

### HUD/DOM 冗余

- 暂停、重开、音量与高对比设置。
- 当前线势使用文字+形状：松、稳、紧、险。
- 节拍窗可选高对比环；关闭也不影响身体和声音线索。
- 调试版显示固定步、快照年龄、输入序号和失稳原因；玩家版隐藏。

## 11. 镜头、动作与声音节奏

- 镜头只做一件事：在预读时给出空间关系，在放势时保留速度感，在停息时把人与世界拉回同一画面。
- 禁止持续摇晃、自动追逐指针或在节拍窗突然切角度。
- 阿迦的加速不只靠位移；由准备姿态、足音间距和披挂拖尾共同表达。
- 音乐让位给交互声音：脚步是拍点，线鸣是张力，脉冲是释放，环境风声是呼吸。
- 安全平台至少保留 2 秒低密度声音，避免每个空隙都被对白或音乐填满。

## 12. 完整游戏叙事骨架

阿迦想追上城市最后一次完整黎明，表面原因是使命，真实原因是他相信一旦停下就再也走不动。他会用速度逃避记忆，却逐渐学会把节拍交给玩家，也学会在必要时拒绝玩家催促。

八个角色转折：抢跑 → 第一次等待 → 用脚尖建立暗号 → 失误时主动抓线自救 → 为记忆物选择慢路 → 与玩家完成三连同步 → 黎明前主动停下 → 不再追光，而把光留给后来者。

四区以呼吸组织：起风断层（吸）→ 悬压城区（屏）→ 回声桥群（呼）→ 晨光终台（静）。玩家快速通过不会被惩罚，但会错过只在停息时出现的痕迹；叙事奖励慢下来，不用收集物强迫慢下来。

## 13. 技术能力需求（不选框架）

- 连续指针投射、曲线编辑、锚点命中与输入量化。
- 固定时间步领域模拟，曲线状态和角色运动可序列化。
- 6–10 秒环形快照或输入重演，并有合法性校验。
- 角色最低限度程序化或骨骼姿态，用于五类可读身体前兆。
- 线势、脉冲和呼吸的渲染反馈，可在灰盒材质中辨认。
- 音频事件能与固定步和暂停同步。
- 自动化覆盖状态迁移、重复输入、暂停恢复、失败回溯和同种子重放。
- 目标设备性能采样：p50/p95 帧时间、长帧、输入到可见反馈、快照内存。

## 14. Gate 2 用户直测计划

### 试玩方式

用户从标题开始直接体验完整 Demo。交付方不进行自主乐趣评分，也不以五人测试作为进入条件。工程侧只确认项目可解析、可启动、关键资产可解析；这些检查不构成 Fun Lock。

### 用户确认问题

- 是否无需外部说明就能完成第一次抓取、拖线和松开放势。
- 是否能区分松、稳、紧、险，并理解最近一次失败。
- 是否会注意阿迦的脚尖、重心、手臂与回望，而不是只盯 HUD。
- 张紧—释放—停息是否形成了节奏，而非普通画线。
- 五轮是否存在递进，最终主动停下是否成立。
- 是否值得进入 visual-director 和正式资产阶段。

只有用户明确批准，Gate 2 才通过。

### 停止信号

- 把输入缩减为一次按住—移动—松开后，仍有超过 2/5 玩家无法解释失败。
- 玩家主要注意 UI 环而不是阿迦身体，且去掉 UI 后节拍完全不可读。
- 为了让玩家成功必须增加路线自动吸附、隐藏容错或自动释放。
- 连续两轮迭代在理解率、失败归因或节拍复述上没有改善。
- 目标设备 p95 帧时间持续高于 20ms，且最小曲线/快照方案仍无法达标。

停止信号由用户试玩反馈触发；出现任一项就回到玩法规格缩减或概念重开，不进入 Gate 3。开发阶段不自行宣告这些体验条件已通过。

## 15. 明确不做

- 不允许玩家直接控制阿迦跑跳。
- 不加入战斗、敌人、技能树、装备、资源搜集或开放世界。
- Gate 2 不做四城区、不写完整对白、不生产正式角色和环境资产。
- 不用随机物理制造戏剧性，不用慢动作替代清晰前兆。
- 不把旧《下一盏灯》灰盒换皮为新玩法。
