# Afterlight Weave concept v1 generation prompt

Mode: OpenAI built-in `image_gen`

Use case: stylized-concept

Asset type: exploratory game environment concept art, pre-Gate-2 visual direction, not a final production asset

Primary request: Create one original cinematic keyframe for a lightweight 3D game called “The Next Lantern”. The image must make the core interaction instantly readable: a small silent traveler uses a hand-held empty lantern while a glowing fiber path, drawn from the traveler’s position, stitches a broken suspended city walkway back together. The route curves visibly around two clean rectangular void gaps, with small stitch-knots at turns. One older completed route remains behind as a dim pale-lilac seam, proving that past choices permanently remain in the world.

Scene/backdrop: a single suspended cross-section of an abstract city floating in a deep near-black aubergine void; architecture made from layered pulp-ceramic slabs with cut edges, a few incomplete arches, sparse distant strata, and one awakened oxidized-glass memory shrine containing two mismatched ceramic cups; no realistic buildings.

Subject: one tiny full-body traveler, readable silhouette, asymmetric folded cloak, empty lantern, cautious forward lean and one foot testing the new path; no visible face required. A luminous incomplete arch ahead acts as the next destination.

Style/medium: highly polished original game concept art; stylized 3D diorama blended with painterly material studies; feasible as modular low-poly browser-game assets; strong silhouettes, deliberate negative space, restrained detail, tactile material separation.

Composition/framing: wide 16:9 landscape, three-quarter orthographic diorama camera, current decision space occupies most of the frame; traveler, glowing path, two void gaps, awakened memory shrine, old path, and destination all visible at once; strong focal hierarchy; no HUD.

Lighting/mood: quiet, intimate, contemplative but not melancholic; soft low ambient light in the void, subtle glow propagation along the fiber, the memory shrine gently waking; no dramatic lens flare.

Color palette: near-black aubergine void #111017, matte paper-clay gray #918B80, oxidized verdigris glass #527C76, active persimmon-orange light fiber #F2A05B, resolved pale-lilac afterlight #B3A5CC, interactive bone-white #E6E0D5.

Materials/textures: only three material families—rough layered paper-clay, translucent oxidized glass, luminous woven fiber; visible compressed layers on platform edges; light thread has thickness and tension rather than looking like neon tubing.

Constraints: exactly one traveler; preserve large areas of negative space; interaction must read at thumbnail size; path starts at traveler and reaches the destination without crossing the void gaps; old route is clearly dimmer than active route; no text, no UI, no logo, no watermark.

Avoid: generic blue-and-gold cyberpunk, neon city, realistic modern skyline, generic fantasy ruins, anime character design, mobile-game isometric look, excessive particles, clutter, motivational symbols, roadsigns, graduation caps, office imagery, photorealism, extra characters.
