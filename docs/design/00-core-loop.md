# 一、游戏核心循环

## 1.1 一句话定位

《归乡录 · Nostos》是一款 2.5D 俯视角短篇推理冒险游戏。玩家扮演失去了漂泊十年记忆的奥德修斯，独自重访五座岛屿，靠检视遗物与唤起凝固的记忆，把那十年一条一条写进归乡录。

**它严格沿用《Obra Dinn 奥伯拉丁的回归》的玩法框架**：船已归港、人已死尽、你带着一件能看见过去的道具回来，唯一的任务是把一本册子填对。

## 1.2 叙事框架为什么能支撑"没有战斗"

对标游戏最核心的结构不是"推理"，而是**时序**：所有事件都已经发生完了，玩家永远是事后抵达的那个人。这一条决定了它不需要战斗、不需要即时反应、不需要失败态。

本作把这条结构翻译成神话语言：

> 奥德修斯在奥吉吉亚岛失去了漂泊十年的记忆。众神的裁决是：在获准归乡之前，他必须自己重建这十年究竟发生了什么。他驾一叶小舟重访五座岛屿——每座岛上事情都已经结束，只剩遗骸、器物、痕迹和极少数留守者。

他随身携带**摩涅莫绪涅之杖**（记忆女神所赐）。触碰带有残留记忆的遗物，那一刻的场景会在原地"定影"成一座凝固的立体画面：他能绕着走、能观察，但不能干预。

这样一来，"没有实时战斗"不是系统被阉割，而是**叙事本身就不允许**。

## 1.3 核心循环

```
抵达岛屿（陶瓶画标题卡）
  ↓
自由探索（固定正交 2.5D · 无计时 · 无死亡 · 无危险）
  ↓
检视遗留物 ──→ 四类证物：物品 / 铭文 / 尸体 / 痕迹
  ↓                    ↓
  ↓            关键证物触发「记忆定影」
  ↓                    ↓
  ↓            画面切换为陶土红/黑釉双色抖动
  ↓            凝固的立体场景，可绕行观察
  ↓            一句"回声"台词 + 每个人物的可辨识细节
  ↓                    ↓
  └──────→ 归乡录（Tab）：下拉框填写条目
                       ↓
              【三条一组校验】三条同时正确 → 永久锁定 + 锁定音
                       ↓
          与 NPC 对话（选项由已得证物 / 已锁条目解锁）
                       ↓
              关键抉择（不可撤销，写入航海旗标）
                       ↓
              离岛（需满足本岛最低锁定条目数）
                       ↓
        [五岛循环] → 伊萨卡尾声 → 六选一结局判定
```

## 1.4 三条一组校验：本作最重要的一条规则

> 实现见 `src/domain/ledger.ts` 的 `checkLocks()`；单测见 `tests/ledger.test.ts`。

**规则**：单独填对一条条目**不会有任何反馈**——没有对勾、没有叉、没有颜色变化、没有音效。只有当尚未锁定的条目里累计出现 **3 条全部正确**时，这三条才会一起永久锁定，界面变为烫金，并播放全作唯一的音效。

**为什么必须原样沿用**：这条规则的意义是从机制上杜绝暴力穷举。如果每条单独校验，玩家可以逐个选项试到对为止，推理就退化成点击遍历。三条一组意味着**你必须先在脑子里建立起三条互相印证的推断，才能换来一次确认**。

**边界规则**：
- 玩家每次只能改动一个下拉框，所以"正确且未锁定"的条目数每次至多 +1；一旦达到阈值，把当时全部正确的条目一并锁定
- 已锁定的条目不再参与后续计数，也不允许再修改
- 填错没有惩罚、没有次数限制、没有提示
- 事实变动（检视了新证物）也会重跑一次校验——因为新解锁的人名可能让一条早已填好、但当时选项还没出现的条目变得有效

## 1.5 无失败态

本作**没有**：生命值、饥饿、计时器、死亡、Game Over、读档惩罚、战斗、追逐、潜行、QTE。

唯一的"损失"是结局时真相不完整。归乡录上空着的每一页，都对应一个永远留在原地的同船者。

## 1.7 硬性禁止项

以下内容**在任何情况下都不加入本作**，它们是对标游戏框架之外的自由发挥：

- 海战、即时战斗、任何形式的动作对抗
- 复杂物理（刚体、绳索、流体、破坏）
- 大量动画（骨骼动画、关键帧序列、过场动画）
- 大无缝开放世界（五座岛完全隔离，岛内也不做无缝大地图）
- 任何额外系统：制作、升级、经济、技能树、随机生成、装备、天赋、好感度数值面板
