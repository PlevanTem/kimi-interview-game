# 四、对话分支条件

## 4.1 对话是什么，不是什么

对话是**条件门控的线性节点树**，不是自由对话系统。没有好感度数值面板、没有关键词输入、没有 AI 生成回复、没有可无限重复刷取的对话。

每岛 2–3 名 NPC，其中**欧律洛科斯是贯穿五岛的常驻角色**（尾声换成雅典娜）。

## 4.2 条件表达式

全部条件可静态求值、无副作用。实现见 `src/domain/conditions.ts`。

```ts
type Condition =
  | { has: FactId }        // 已获得某事实（检视过某件证物 / 看过某段定影）
  | { locked: string }     // 某条归乡录条目已锁定
  | { lockedCount: number} // 全局已锁定条目数 ≥ n
  | { flag: FlagId }       // 某抉择旗标已置
  | { trust: number }      // 欧律洛科斯的信任度 ≥ n
  | { not: Condition }
  | { all: Condition[] }
  | { any: Condition[] }
```

## 4.3 三条设计规则

### 规则一：对话不产生新事实，只确认已知事实

NPC 只会在你已经掌握相应证物时才愿意谈那件事。

```ts
{ node: 'has-amulet', when: { has: 'F-lotus-amulet' } }
```

**为什么**：如果对话能直接给出答案，玩家会先把所有 NPC 的对话点一遍，推理就被绕过去了。对话的作用是**确认与补充语气**，不是**发放线索**。

唯一的例外是解锁人名的两处（如家书里提到铜戒），而那些都写在**证物文本**里，不在对话里。

### 规则二：NPC 会说谎，但不会凭空说谎

每一个谎言在场景中都有一件反证物。

| 谎言 | 反证 |
|---|---|
| 欧律洛科斯（岛 1）：「我在船上守着。」 | 属实——但 `M-103` 显示是他抱住你的腰想拦你 |
| 欧律洛科斯（岛 3）：「你查你的，别查我。我有什么好查的。」 | `M-302` 直接拍下他站在门外没动的那一刻 |
| 波吕斐摩斯（岛 1，未承认前）：装作不知道你是谁 | 他其实一直在数天数，等的就是这个名字 |
| 埃俄罗斯：「我知道不是你。」 | 他石板最后一行写着「其人自己并未开袋。然亦不能不算其过。」 |

玩家**不需要**"揭穿"谎言，也没有对峙小游戏。你只是拿到定影，然后 NPC 的入口节点自动切换到承认那一支。

### 规则三：常驻角色的态度串起全程

欧律洛科斯有一个隐藏的 `trust` 数值，由五岛的对话选项与抉择累加，分三档：

| 档位 | 条件 | 表现 |
|---|---|---|
| 敌意 | trust ≤ −2 | 只给最短的答案，岛 4 不说出他的动机 |
| 疏远 | −1 ≤ trust ≤ 1 | 正常但克制 |
| 信任 | trust ≥ 2 | 岛 4 坦白他当时在想什么，并说出那句「这件事里没有一个人是清白的」 |

trust 从不显示为数字，玩家只能从他的说话方式感觉出来。

## 4.4 入口节点选择

每个 NPC 有一组带条件的入口，取**第一个满足者**，最后一项必须无条件（兜底）。这保证 NPC 的开场白永远反映玩家当前的进度。

```ts
entries: [
  { node: 'knows',    when: { flag: 'confessed' } },      // 已承认过身份
  { node: 'shouted',  when: { has: 'F-cyclops-shouted' }},// 已看过 M-103
  { node: 'first' },                                       // 兜底
]
```

单测 `tests/conditions.test.ts` 强制校验：
- 每个入口指向的节点真实存在
- 最后一个入口必须无条件
- 每个选项的 `goto` 指向存在的节点
- 每个节点至少有一个选项（哪怕只是「（结束对话）」）

## 4.5 逐岛对话门控表

### 岛 0 · 欧律洛科斯
| 入口节点 | 条件 | 内容 |
|---|---|---|
| `after-lock` | `lockedCount ≥ 3` | 他听见了锁定音，说佩里墨得斯刚从他旁边走过去 |
| `has-amulet` | `has F-lotus-amulet` | 认出海豚牌子是谁的 |
| `intro` | 兜底 | 教学：杖是什么、为什么他跟着你 |

### 岛 0 · 忘了名字的人
| 入口节点 | 条件 | 内容 |
|---|---|---|
| `told` | `locked L-002` | 「写上去了？那我就能走了。」 |
| `amulet` | `has F-lotus-amulet` | 看见护身符，眼睛慢慢睁大 |
| `first` | 兜底 | 「我知道我有名字，就像我知道我有影子一样。」 |

### 岛 1 · 波吕斐摩斯
| 入口节点 | 条件 | 内容 |
|---|---|---|
| `knows` | `flag confessed` | 告诉你羊圈第三根桩子底下压着一块刻名的木牌 |
| `shouted` | `has F-cyclops-shouted` | 「那你现在知道他叫什么了。」→ 承认 / 否认两支 |
| `first` | 兜底 | 他在数天数，不知道来者是谁 |

**关键分支**：选「奥德修斯。」（承认）置 `confessed`，随后他说出全作最重要的一段设定——你的记性是被拿走的，条件就是你必须记不起自己做过什么。

### 岛 3 · 欧律洛科斯
| 入口节点 | 条件 | 内容 |
|---|---|---|
| `caught` | `has F-aiaia-outside` | 他看见杖还亮着，脸色变了 |
| `main` | 兜底 | 「那扇门我不进。」 |

**关键分支**：`caught` 下有三个回应，其中「门楣上那行字也是你刻的」是一条只有细心玩家会问的支线——他承认刻那行字不是为了警告后来的人，是为了说服自己当时不是怕。

### 岛 4 · 菲罗提俄斯
| 入口节点 | 条件 | 内容 |
|---|---|---|
| `named` | `locked L-405` | 他转过头来了 |

**关键分支**：选「对不起。我睡着了。」他会摇头，然后说出全作最锋利的一句：「你醒过来以后，你也吃了。……我不怪你。我只是希望你写的时候，别把这一句漏掉。」这直接铺垫 C-5 的「归罪自己」选项。
