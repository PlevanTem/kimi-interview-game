# 二、物品线索系统

## 2.1 三条铁律

1. **只解锁知识，不做背包管理**
   证物永不消耗、永不组合、永不携带出岛。玩家真正拥有的东西只有一个：**已知事实集合**（`facts: Set<FactId>`）。没有背包界面、没有格子、没有重量、没有丢弃。

2. **选项由证物驱动**
   归乡录下拉框里出现的每一个人名，都必须先由某件证物或某段记忆揭示过。玩家永远不会看到没有依据的名字。

3. **无失败态**
   填错没有惩罚、没有次数限制、没有计时。

## 2.2 证物的五种类型

| 类型 | `kind` | 说明 | 例子 |
|---|---|---|---|
| 物品 | `object` | 可拿在手里的遗留物 | 刻名的护身符、烧焦的橄榄木桩、断齿的木梳 |
| 铭文 | `inscription` | 写下来的东西 | 界碑、洞壁刻痕、没寄出的家书、风王的记事石板 |
| 尸体 | `body` | 遗骸，多数带一件可辨识的随身物 | 带铜扣的遗骸、握着断桨的遗骸 |
| 痕迹 | `trace` | 现场留下的物理证据 | 沙上的脚印、并绑的羊毛与麻绳、洞口的血手印 |
| 证词 | `testimony` | NPC 说出的、可被写进册子的话 | （由对话节点写入事实，不作为场景中的可检视对象） |

## 2.3 数据结构

```ts
interface Evidence {
  id: string                 // 'E-103'
  island: IslandId
  kind: EvidenceKind
  name: string               // 「带铜扣的遗骸」
  examine: string[]          // 检视面板正文，逐段
  position: Vec2
  grantsFacts: FactId[]      // 检视后写入玩家的已知事实集合
  unlocksOptions?: string[]  // 额外解锁的下拉选项
  tableau?: string           // 若存在，检视后可按 E 进入记忆定影
}
```

## 2.4 记忆定影（Tableau）

定影是本作对《Obra Dinn》"怀表回忆"的等价物，但适配 2.5D 俯视角：

```ts
interface Tableau {
  id: string
  title: string              // 「独眼熄灭时」
  echo: string               // 进入时的一句回声台词
  echoSpeaker: string
  center: Vec2               // 定影中心，玩家可在附近有限范围绕行
  figures: TableauFigure[]   // 凝固的人物
  grantsFacts: FactId[]
}

interface TableauFigure {
  id: string
  label: string              // 「举着木桩的人」——注意不是名字
  position: Vec2
  facing: number
  pose: 'stand' | 'kneel' | 'lie' | 'reach' | 'flee' | 'sit'
  detail?: string            // 该人物的可辨识细节
  giant?: boolean
}
```

**设计要点**：

- 图中人物的 `label` 永远是**描述而不是名字**（「举着木桩的人」「解绳的一双手」）。把描述接到名字上，正是玩家要做的推理工作。
- `detail` 里藏的是可交叉引用的细节：铜扣上的鸟、右臂的旧疤、左手无名指的铜戒。同一个细节会在别的岛以另一种形式再次出现。
- 定影**不可干预**，也不能改变任何东西。玩家只能看。

## 2.5 选项池：为什么人名要门控，死因不用

| 池 | 是否门控 | 理由 |
|---|---|---|
| `crew`（十二名同船者） | **是**，按 `revealedBy` 事实解锁 | 与《Obra Dinn》里"船员名册要靠画像和证词逐个认出来"一致。指认谁，就是全部的难度所在。 |
| `lotus-cause` / `cyclops-method` / `aeolia-motive` 等 | **否**，一开始就全部列出 | 与《Obra Dinn》的"命运列表"一致。摆出四个可能性不构成剧透——难点不是猜有哪些可能，而是确定是哪一个。 |

实现见 `src/domain/ledger.ts` 的 `availableOptions()`。

## 2.6 跨岛互证：名册是全作的推理骨架

十二名同船者贯穿五座岛。**同一个名字会在多座岛以不同的证物形式复现**，这是本作最重要的线索织法：

| 人物 | 揭示他名字的东西 | 他后来又出现在 |
|---|---|---|
| 佩里墨得斯 | 岛 0 的刻名护身符 | —— |
| 波利忒斯 | 岛 1 遗骸胸口的铜扣（刻着一只画得像抹布的鸟） | —— |
| 安提福斯 | 岛 1 遗骸右臂常年握桨磨出的旧痕 | —— |
| 欧律巴忒斯 | 岛 1 遗骸旁散落的骨骰 | —— |
| 厄尔佩诺尔 | 岛 1 酒囊上的花哨绳结 / 岛 3 的断齿木梳 | 岛 4 海边遗骸头发里的同一把梳子 |
| 得摩斯 | 岛 2 那封没寄出的家书的落款 | —— |
| 乌拉尼奥斯 | 岛 2 风向盘背面的炭笔字迹 | 岛 2 礁石上的遗骸 |
| 克里托斯 | 岛 2 家书里一句闲话：「他昨晚一直在擦他那枚铜戒」 | 岛 2 定影中解绳的那只手戴着它 → 岛 3 腰带内侧的戒指压痕 → 岛 4 船骸下那只戴戒的手 |
| 弥塞诺斯 | 岛 3 刻名的骨笛 | 岛 3 屋角骸骨旁的另外半支笛子 |
| 菲罗提俄斯 | 岛 4 山坡上饿死的遗骸 | —— |

**克里托斯这条链是全作最长的一条**：家书里的一句闲话 → 定影里一双看不见脸的手 → 另一座岛上腰带内侧的压痕 → 最后一座岛上一只戴着戒指的手。四座岛，四种证物，指向同一个人。
