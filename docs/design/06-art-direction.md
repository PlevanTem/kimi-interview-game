# 七、美术方向

## 7.1 一句话

**低多边形三维 + 古希腊黑绘式陶瓶画**。全部几何体程序化生成，零外部资产。

## 7.2 配色

整部游戏只用这一组颜色。黑绘式陶瓶的物理限制就是本作的美术纪律：一种陶土底色、一种黑釉、一点点用来点睛的红与白，再无其他。

```
陶土红 terracotta  #b44a2e   主角、强调、可交互高亮、记忆定影的"纸"
黑釉   glaze       #1a1310   人物剪影、轮廓、界面底、记忆定影的"墨"
陶底   clay        #d9a05b   地面与大部分几何体
象牙白 ivory       #edd9b0   文字、细节刻线、羊、柱
海蓝   sea         #2e5a6b   限定使用，只给海与水
金     gold        #c8912f   已锁定的归乡录条目、神性物件、牛群
深陶   shade       #8a5a33   阴影面、远景、浅滩
```

**任何新增颜色都必须先加到 `src/render/palette.ts`，不允许在组件里写死色值。**

## 7.3 几何语言

- 全部图元来自 three.js：`box` `cylinder` `cone` `icosahedron` `dodecahedron` `torus` `ring` `plane`
- 统一 `flatShading`，低分段数（5–9 段），硬边，无平滑
- 无贴图、无法线、无 PBR 参数调校，`roughness` 一律 0.85–1.0

### 人物

低多边形人形，由六个图元拼成：上窄下宽的锥台躯干（希腊长袍最省事也最准确的抽象）、二十面体的头、两条手臂、两条腿、一圈腰带。

- **黑绘式剪影**：所有 NPC 与记忆中的人物都是纯黑釉
- **唯一的例外是玩家**：奥德修斯用陶土红，全场只有他一个人是红的
- 腰带那一圈是陶瓶画上唯一允许的红 / 白细节

**姿态只改几个关节角度和整体高度**，共六种：`stand` `kneel` `lie` `reach` `flee` `sit`。没有骨骼、没有关键帧、没有动画曲线。

## 7.4 记忆定影：双色有序抖动

这是对《Obra Dinn》1-bit 抖动渲染的致敬，但换了一套依据：**古希腊黑绘式陶瓶本来就只有两种颜色**（陶土红的底、黑釉的形），所以"把画面量化成两色"在这里不是风格化，而是回到材料本身。

**实现**（`src/render/DitherPass.tsx`）刻意保持在最低限度：
- 一张 `WebGLRenderTarget`
- 一个全屏四边形
- 一个 4×4 Bayer 有序阈值矩阵
- **不引入任何后处理库**

**关键技术点**：

1. **抖动图案钉在屏幕空间**（`gl_FragCoord`），玩家移动时图案不跟着物体走。这正是那种"版画感"的来源，与对标游戏一致。

2. **色彩空间**：render target 的 `texture.colorSpace` 必须设为 `SRGBColorSpace`。否则 target 里存的是线性亮度，而阈值判定用的是感知亮度，结果几乎每个像素都落在阈值以下，整屏被压成纯黑。（这个 bug 在开发中真实出现过，截图确认后才定位到。）

3. **双色常量用 `setHex(hex, LinearSRGBColorSpace)` 存入**：这个 pass 全程在 sRGB 编码空间里工作，用 `new Color('#...')` 会把色值再转一次线性，输出就偏暗了。

4. **不是均匀二值化**：先整体推高曝光（`× 1.55`），再拉开对比（`(lum − 0.42) × 1.9 + 0.5`），让陶底几乎全是"纸"、人形几乎全是"墨"，只在轮廓与受光转折处留下一圈网点。均匀的中间调网点看起来只是"脏"。

5. **抖动只对亮度做，不分通道做**——分通道会渗出彩色噪点，破坏双色。

6. **进出定影有 0.25 秒过渡**（`uAmount` 插值），避免画面硬切。

**定影时的场景设置**：背景与雾换成陶底色、环境光提到 2.4。黑绘式陶瓶是"亮底 + 黑形"，所以定影反而要比探索更亮。

## 7.5 光照

- 环境光：象牙白，探索 0.85 / 定影 2.4
- 主光：象牙白平行光，从 `(12, 20, 8)` 打下，强度 2.0，投 1024² 阴影
- 补光：海蓝平行光，从 `(-10, 8, -12)` 打来，强度 0.5——让阴影面偏冷，模拟海面反光
- 局部：火塘与证物高亮各带一个小范围点光源

## 7.6 动画预算

**只有三种循环动画，再无其他**：

1. 火焰的纵向呼吸（`sin`，±12%）
2. 证物标记的缓慢自转与上下浮动
3. 记忆定影中人物极轻微的呼吸浮动（±0.025 单位）

界面上只有一个动画：锁定提示条的入场（320ms，`prefers-reduced-motion` 下关闭）。

**没有**：骨骼动画、行走循环、过场动画、镜头运动、粒子系统、屏幕震动。

## 7.7 界面版式

整套界面模仿黑绘式陶瓶的版面：

- 深色底（`rgba(20,14,11,0.94)`）、浅色字
- **无圆角、无阴影渐变、无毛玻璃**
- 标题用大字距（`letter-spacing: 0.3em+`），配一行希腊原文作装饰
- 正文字体优先宋体系（`Songti SC` / `Noto Serif CJK SC`），衬线感对应陶瓶铭文
- 地面四周有一圈**回纹（meander）边饰**，用一串小方块拼成，是希腊器物最标志性的装饰母题
- 全屏叠一层极轻的陶器颗粒噪点（`radial-gradient` + `mix-blend-mode: multiply`），把 WebGL 的干净边缘做旧

## 7.8 视觉验收标准

- [ ] 探索时能一眼看出这是一座**岛**（陆地 / 浅滩 / 海三层）
- [ ] 全场只有奥德修斯一个人是红的
- [ ] 进入记忆定影时画面明确切换成陶土红 / 黑釉双色，退出后恢复
- [ ] 定影里陶底是**大片连续的陶土红**，人形是**大片连续的黑**，网点只出现在转折处
- [ ] 已锁定的归乡录条目是烫金的，未锁定的是暗陶色
- [ ] 全程没有出现配色表以外的颜色
