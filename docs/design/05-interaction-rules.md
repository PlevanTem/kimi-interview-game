# 六、交互规则文档

## 6.1 操作表

| 输入 | 行为 |
|---|---|
| `W` `A` `S` `D` / 方向键 | 八向移动。恒定速度，无加速度、无惯性、无冲刺、无翻滚 |
| `E` / `Enter` | 检视证物 / 进入记忆定影 / 与 NPC 交谈 / 触发抉择 / 离岛（按优先级自动判定） |
| `Q` | 退出记忆定影 / 收起检视面板 |
| `Tab` | 打开或合上归乡录 |
| `空格` | 推进对话（等同选择第一项）/ 关闭检视与后果面板 |
| `1` `2` `3` `4` | 选择对话选项 |
| `Esc` | 有面板时关闭面板，否则暂停 |
| `P` | 暂停 |
| `M` | 静音 |

## 6.2 `E` 键的优先级

站在多个可交互对象附近时，按下列顺序取第一个（实现见 `src/domain/interaction.ts`）：

```
1. 证物（半径 1.75）
   ├─ 若已检视过且带定影 → 「举杖唤起记忆」
   └─ 否则               → 「检视」
2. NPC（半径 2.15）
3. 抉择点（半径 2.15，且满足 availableWhen，且尚未做过）
4. 离岛点（半径 2.35）
   ├─ 本岛已锁定条目 ≥ 门槛 → 「登船离岛」
   └─ 否则                  → 「还写不完这一段（本岛已锁定 n / m 条）」
```

**离岛门槛被排在最后，且不满足时只给提示而不是禁止**——本作没有硬门禁，只有"你还没准备好把这一段写完"。

## 6.3 相机

**固定 2.5D 正交相机，不可旋转。**

- 投影：正交（`OrthographicCamera`）
- 角度：偏航 45°、仰角约 34°（相机偏移向量 `(15, 17.5, 15)`）
- 缩放：按「纵向可见世界单位数」换算，`zoom = 视口高度 / span`。探索 `span = 27`，记忆定影 `span = 11`
- 跟随：阻尼跟随玩家（`MathUtils.damp`，系数 6），定影时改为注视定影中心

**为什么不给玩家旋转相机**：可旋转的相机会逼着我们做遮挡剔除、透明墙、动态裁剪。那些都属于"对标游戏框架之外自己发明的系统"。本作的做法是**每座岛的地形都照着这唯一一个机位手工排布**，高物体一律靠边放，从源头就不会出现遮挡。

单测 `tests/movement.test.ts` 的「岛屿布局可用性」会强制校验每件证物、每个 NPC、每个出生 / 离岛 / 抉择点都真的走得到——这条测试在开发中确实抓出了三处把证物埋进墙里的布局错误。

## 6.4 移动与碰撞

- 碰撞体：玩家是一个半径 `0.42` 的圆；地形是轴对齐盒或圆柱。**只有这两种形状，没有第三种**
- 解算：把候选位置先钳制到岛屿边界，再逐块推出，沿穿透最浅的轴推出（玩家会沿墙滑行而不是被弹开），迭代两轮足以处理墙角
- 速度：`4.2 单位/秒`，对角线做归一化，斜着走不比直着走快
- **子步进**：长间隔会被拆成每步不超过 `0.35` 单位的若干子步逐个解算

> **关于子步进**：早期实现是把单帧 `delta` 一刀砍到 50ms 上限来防穿墙。这在低帧率下会让玩家**莫名其妙地变慢**——e2e 测试在软件渲染下只跑到 6 fps，实测移速只剩三成。正确做法是子步进：`delta` 只封顶到 0.25 秒（防止切回标签页时冲出半个岛），防穿墙交给子步进保证。这样「移速与帧率无关」和「任何帧率下都不穿墙」两个性质同时成立。

**没有**：刚体物理、重力、跳跃、高度差穿越、可推动物体、绳索、载具。台阶、祭坛、猪圈、石屋地面这类齐膝高的东西一律**不阻挡移动**——它们是抬高的地面，不是墙。

## 6.5 归乡录的交互纪律

这是本作最需要克制的一块界面。

**允许**：
- 下拉框选择（选项来源见《物品线索系统》2.5）
- 随时打开 / 合上，随时改动未锁定的条目
- 查看同船者名册（未揭示的显示为 `？？？`）

**禁止**：
- ❌ 任何"这条对不对"的即时提示——没有对勾、没有叉、没有颜色区分、没有音效
- ❌ 进度条、正确率、剩余条数提示
- ❌ 提交按钮 / 校验按钮（校验是被动触发的，玩家不能主动"交卷"）
- ❌ 撤销已锁定的条目

**唯一的正反馈**：三条同时正确时整组变烫金 + 播放锁定音 + 屏幕上方浮出一条列出这三条题面的提示。

## 6.6 无失败态清单

本作**不存在**以下任何一项：

生命值 · 护甲 · 饥饿 · 体力 · 精神值 · 计时器 · 倒计时 · 死亡 · Game Over · 读档惩罚 · 战斗 · 敌人 · 伤害 · 追逐 · 潜行 · 侦测 · QTE · 失败重来 · 分数 · 评级 · 成就压力

暂停面板上直接写着这句话：**「这里没有计时，也没有会追上你的东西。慢慢来。」**

## 6.7 音频

全作只有**一个**音效：三条落定时的锁定音——一个用 WebAudio 现场合成的纯五度（G4 + D5，三角波，1.6 秒衰减）。不加载任何音频资产。

`M` 键静音。音频不可用时静默降级——它从来不是玩法的必要条件。

## 6.8 无障碍

- 全部面板使用 `role="dialog"` + `aria-modal` + `aria-label`
- 归乡录的每个下拉框都有描述性 `aria-label`（题面 + 槽位名）
- 锁定提示使用 `role="status"`，屏幕阅读器会朗读
- 全部功能可纯键盘完成；全部按钮可 Tab 聚焦，`:focus-visible` 有明显轮廓
- 尊重 `prefers-reduced-motion`：关闭提示条的入场动画
- 不依赖颜色单独传达信息（已锁定的条目除了变金色，还显示「已落定」印记）
